# История изменений

**Русский** · [English](CHANGELOG.md)

## 2.2.1 - параметры техники в одном файле

- Изменено: все числа машины, вертолёта, дрона, правил полёта и подвеса теперь лежат в `rust/vehicles.json` (встроен в приложение); поведение не изменилось. На десктопе другой файл можно попробовать через `RAYTRACE_VEHICLES=путь` (docs/vehicles.md)

## 2.2.0 - полёт

- Добавлено: вертолёт и дрон с аркадным управлением (стики отпущены — висение, мягкая посадка или авария) и три воздушные миссии: гонка по кольцам, груз на подвесе (вертолёт) и разведка дроном
- Добавлено: в списке теперь шесть миссий; новый HUD полёта (высота, скорость, состояние троса), кольца, площадки и зоны разведки в мире
- Десктоп: клавиши полёта (W/S тангаж, A/D крен, Q/E рысканье, Up/Down высота); `RAYTRACE_MISSION=4` запускает миссию с кольцами
- Известно: городов и спасения пока нет; блокировка экрана посреди миссии начинает её заново

## 2.1.0 - миссии

- Добавлено: миссии: список из четырёх случайных миссий (две доставки груза, две гонки по чекпойнтам) со световым столбом цели и кольцами чекпойнтов, таймером, прочностью груза (удары, жёсткие посадки и перевороты его портят), стрелкой и расстоянием до цели, паузой и экраном итогов
- Добавлено: медали бронза / серебро / золото по времени и состоянию груза, награды деньгами, сохранённый профиль (деньги, лучшая медаль и время по миссиям; битый файл сохраняется как `.bak`), «Обновить» для нового списка
- Добавлено: главное меню (Миссии / Свободная езда / Сцены / Качество) с деньгами; десктоп: `RAYTRACE_MISSION=<0..3>` запускает миссию, `M` прерывает (docs/game.md)

## 2.0.0 - игра про бездорожье

- Добавлено: игра рядом с просмотром сцен: «Свободная езда» по случайному уровню (у каждого уровня есть seed, он виден в HUD; тот же seed даёт тот же уровень)
- Добавлено: холмистый ландшафт по seed с камнями и деревьями, аркадный внедорожник с подвеской, заносом (ручник) и столкновениями, камера следом, сенсорное управление (левый стик: руль и газ, правый стик вниз: тормоз) и клавиатура на десктопе
- Добавлено: растровый рендер (режим C) с тайлами ландшафта по уровням детализации, туманом, небом и тенью от солнца; разрешение Низкое / Среднее / Высокое на стартовом экране
- Добавлено: стартовый экран (Свободная езда / Сцены / Качество); десктоп: `raytrace-desktop --game [seed]` (docs/game.md)
- Без изменений: режим «Сцены» с трассировкой и файлы сцен

## 1.8.0 - призма

- Добавлено: сцена «Призма»: солнце через низкую щель проходит стеклянную призму и раскладывается в спектр на полу; сама призма показывает цветные кромки
- Добавлено: `ior` и `dispersion` у стекла, фигура `prism` и `caustic_receivers` для файлов сцен (docs/scenes.md); настройка `scene`: 0 Классика, 1 Солнечная комната, 2 Витрина, 3 Призма, 4 = загруженный файл (раньше 3)
- Добавлено: фотонные проходы (фотоны солнца через призму в карту фотонов на полу и стенах, усреднение по кадрам) и «ведущая» длина волны для лучей камеры сквозь стекло с дисперсией

## 1.7.0 - сцены

- Добавлено: сцены теперь данные (JSON): три встроенные (Классика — прежняя сцена, Солнечная комната, Витрина материалов) и свои файлы из папки; выбор на вкладке «Сцена» (Android и Linux); формат в docs/scenes.md
- Добавлено: солнечный свет (направленный, мягкие тени, день / закат / ночь по настройке «Небо»), цветные стёкла, окрашивающие проходящий свет, глянцевый материал (матовая основа под зеркальным слоем), цветное стекло, скруглённые и вращающиеся боксы
- Добавлено: «Солнечная комната» (солнце через щель в потолке на цветные стёкла, зеркало, золото, матовые, глянцевые и прозрачные предметы) и «Витрина материалов»
- Изменено: тени от всех источников считаются аналитически по примитивам (без трассировки всей сцены); шейдер генерируется из списка примитивов сцены

## 1.6.0 - вертолётная камера

- Добавлено: режим камеры «Вертолёт» (вкладка «Сцена», есть и в десктопной панели): левый стик — поворот (x) и движение вперёд/назад (y), правый стик — высота (y) и движение боком (x); взгляд зафиксирован слегка вниз. Десктоп: A/D — поворот, W/S — вперёд, стрелки вверх/вниз — высота, влево/вправо — боком
- Изменено: у настройки `cam_mode` появилось третье значение (2)

## 1.5.0 - стиль PlayStation 1

- Добавлено: переключатель «Стиль PlayStation 1» (вкладка «Качество», есть и в десктопной панели): короткая сторона экрана рендерится в 240 px и показывается жёсткими пикселями (без фильтрации), цвет урезается до 15 бит (по 5 на канал) с упорядоченным дизерингом 4x4 по пикселям источника, позиция камеры привязывается к сетке 1/24, анимация идёт 12 к/с, без субпиксельного дрожания; заменяет масштаб рендера, временное сглаживание и денойзер продолжают работать
- Замер на POCO F3 («Баланс», гибрид): 43-47 fps при 240x528, GPU около 20 мс
- Пробовали и отказались: целочисленная (фиксированная точка) SDF губки Менгера, на Adreno примерно на 60% медленнее (docs/bench.md)

## 1.4.0 - версия для Linux

- Добавлено: `raytrace-desktop` для x86-64 Linux (окно winit + панель настроек на egui, камера мышью и клавиатурой, настройки в `~/.config/raytrace/settings.ini`); пакеты: tar.gz, AppImage и `PKGBUILD` для Arch
- Изменено: `Gfx` создаётся из любой поверхности wgpu и рисует необязательный оверлей после финального прохода; пресеты и ключи настроек теперь есть и в Rust
- Android-приложение не менялось (остаётся 1.3.0)

## 1.3.0 - аналитические теневые лучи

- Изменено: теневые лучи используют аналитические окклюдеры с грубой фазой вместо трассировки всей сцены: сферы аналитические; для бокса Менгера проверка по плоскостям (slab), для тора проверка ограничивающей сферы, и только если луч достигает этих объектов, выполняются КОРОТКИЕ ограниченные марши
- Изменено: у «Баланса» по умолчанию 4 отскока

## 1.2.0 - глобальное освещение в половинном разрешении

- Добавлено: настройка «Разрешение GI» (Полное / Половина / Четверть) на вкладке «Свет»; действует только в гибридном режиме при включённом GI (в режиме трассировки путей GI остаётся внутри прохода trace; при выключенном GI ничего не откладывается); пресеты: у «Скорости» GI выключен (разрешение не важно), Баланс = Половина, Качество = Полное
- Добавлено: проходы GI в половинном/четвертном разрешении (gi_trace, gi_temporal, gi_atrous, composite; работают только для Половины/Четверти, «Полное» считает GI внутри прохода trace как в 1.1) со своим временным накоплением, a-trous шумоподавлением и билатеральным апсемплингом
- Добавлено: тайминги проходов GPU в режиме HUD «Полный» (если поддерживаются timestamp-запросы)
- Изменено: GI по умолчанию считается в половинном разрешении
- Измерено: на POCO F3 при фикс. 0.33x гибрид Половина даёт +46% fps против Полного (10.4 -> 15.2 fps), Четверть +53%; см. docs/bench.md

## 1.1.0 - экранные стики и свободная камера

- Добавлено: два экранных стика геймпада (левый - движение / масштаб, правый - обзор / вращение)
- Добавлено: режим свободного полёта камеры наряду с облётом
- Добавлено: четыре настройки вкладки «Сцена» - режим камеры, экранные стики, скорость движения, скорость обзора

## 1.0.0 - первый релиз

- SDF-сцена на Rust + wgpu (Vulkan): гибридный и прогрессивный режим трассировки путей
- Временная репроекция с проверкой по глубине / нормали / id, ограничением по соседям и джиттером Хэлтона
- A-trous шумоподавление (0-3 прохода), апскейл Catmull-Rom, резкость, экспозиция, тонмаппинг, дизеринг
- Адаптивное разрешение под целевой fps, шахматная трассировка, ограничение частоты кадров
- Пресеты (Скорость, Баланс, Качество), переключатели теней / глобального освещения / каустик / отражений, цвета ламп, небо, авто-облёт
- Интерфейс настроек Material 3 Expressive (android-ui-kit): пять вкладок, темы, вибрация, HUD; русский и английский
- Защитный регулятор: очень медленные кадры автоматически снижают масштаб рендера и число сэмплов
- Жесты: вращение, щипок для масштаба, двойной тап сбрасывает камеру
