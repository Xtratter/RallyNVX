# Graphics II Implementation Plan (v2.6)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline). Steps use checkbox syntax.

**Goal:** generated trees/bushes/rocks/grass, dynamic daylight with clouds, shallow lakes, richer city (palettes, cornices, lamps, even asphalt with marks).
**Architecture:** pure CPU modules first (daylight, nature meshes, scatter, water level) tested on the host; then GPU wiring through the existing model pipeline (uniform scale added to `MInst`), a new water pipeline and shader changes. No new textures.
**Tech Stack:** Rust, wgpu 24, WGSL. Phone verification replaces CI screenshots (user request).
**Spec:** docs/superpowers/specs/2026-10-12-graphics2-design.md

## Global Constraints
- Everything generated by code, deterministic per seed; no external assets.
- Phone: >= 60 fps at High (120 now); quality scales cost: grass cap Low 0 / Medium 1500 / High 3000 (by `city_radius` 300/400/450).
- Gameplay physics, missions and collision shapes unchanged except water drag (`cars.*.water_drag`) and mission points never in water.
- Docs EN+RU; version 2.6.0 (versionCode 17); co-author trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Triangle budgets: tree <= 320, bush <= 150, rock <= 120, grass tuft 6.
- Host test command: `cd rust && cargo test --lib`; device build: `bash tools/build-native.sh` then gradle (see Task 8).

## Review Focus
- Water level vs spawn, city plateaus and flat seeds: spawn, cities and mission points never flooded; no water on flat seeds (Task 3).
- Daylight: continuity of sun/colours over the cycle, no NaN at elevation extremes, shadow `up` vector, paused time (Task 1, 5).
- Scatter determinism and cache: same camera cell gives the same tufts; no tufts in water/city/rock (Task 2, 4).
- Instance capacities: model instance buffer cap, props+bushes+grass counts never exceed it (Task 4).
- Water mesh: only tiles near the level, depth sign, alpha blending order, no z-fighting at shore (Task 6).
- Asphalt marks: none inside intersections, aligned to the strips, no marks on non-street tiles (Task 7).
- Windows/models reflection brightness does not blow out at dusk (Task 5, 7).

```rust
//! Dynamic daylight: the sun moves along a day arc; sky, fog and light colours follow its elevation. No night.
use super::math::{v3, V3};
use super::terrain::hash01;
pub const DAY_SECONDS: f32 = 720.0;
pub const ELEV_MIN_DEG: f32 = 10.0; pub const ELEV_MAX_DEG: f32 = 60.0;
#[derive(Clone, Copy, Debug)]
pub struct Daylight { pub sun: V3, pub sun_col: [f32; 3], pub sky_top: [f32; 3], pub sky_hor: [f32; 3] }
fn mix(a: [f32; 3], b: [f32; 3], k: f32) -> [f32; 3] { [a[0] + (b[0] - a[0]) * k, a[1] + (b[1] - a[1]) * k, a[2] + (b[2] - a[2]) * k] }
fn smooth(a: f32, b: f32, x: f32) -> f32 { let t = ((x - a) / (b - a)).clamp(0.0, 1.0); t * t * (3.0 - 2.0 * t) }
pub fn elevation_deg(phase: f32) -> f32 {
    let mid = (ELEV_MIN_DEG + ELEV_MAX_DEG) * 0.5; let amp = (ELEV_MAX_DEG - ELEV_MIN_DEG) * 0.5;
    mid - amp * (std::f32::consts::TAU * phase).cos()
}
pub fn daylight_at_phase(phase: f32) -> Daylight { daylight_at(phase, 0.9) }
fn daylight_at(phase: f32, azimuth0: f32) -> Daylight {
    let e = elevation_deg(phase).to_radians();
    let az = azimuth0 + phase * std::f32::consts::PI;
    let sun = v3(e.cos() * az.cos(), e.sin(), e.cos() * az.sin()).norm();
    let warm = 1.0 - smooth(10.0, 40.0, elevation_deg(phase));
    let k = 2.6 - 0.9 * warm;
    let base = mix([1.0, 0.93, 0.80], [1.0, 0.62, 0.36], warm);
    Daylight { sun, sun_col: [base[0] * k, base[1] * k, base[2] * k],
        sky_top: mix([0.22, 0.42, 0.80], [0.30, 0.34, 0.62], warm), sky_hor: mix([0.70, 0.80, 0.90], [0.96, 0.68, 0.50], warm) }
}
pub fn daylight(seed: u64, t: f32) -> Daylight {
    let phase0 = hash01(seed ^ 0xDA7, 3, 5);
    let az0 = hash01(seed ^ 0xDA8, 7, 1) * std::f32::consts::TAU;
    daylight_at(((phase0 + t / DAY_SECONDS) % 1.0 + 1.0) % 1.0, az0)
}
#[cfg(test)] #[path = "daylight_tests.rs"] mod tests;
```
