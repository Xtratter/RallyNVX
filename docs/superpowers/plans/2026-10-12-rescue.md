# Rescue Missions Implementation Plan (v2.7)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline).

**Goal:** helicopter rescue missions (pick people up at 1-3 sites, deliver to a base pad).
**Architecture:** pure rules in `airgen` (points, people) and `airrun` (state machine), thin wiring in `missions/world/app/meta`, one generated person model, Kotlin card/HUD texts.
**Tech Stack:** Rust (host tests), wgpu model pipeline, Kotlin Activities.
**Spec:** docs/superpowers/specs/2026-10-12-rescue-design.md

## Global Constraints
- Deterministic per seed; no new files/assets; EN+RU texts; version 2.7.0 (versionCode 18); trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`; device checks with the user's permission (granted for this stage), short, Termux in front at the end.
- Existing missions behave as before except the sixth-slot rotation (`round % 3`).

## Review Focus
- Boarding dwell: resets on takeoff/leaving the circle; a bounce (Landed -> Flying -> Landed) does not keep progress; boarding only the current target.
- Points: never in water/city, gentle, spaced; fallback in `nearest_landing` when nothing fits.
- Old profile files and the menu/state array layout still load; kind id 5 round trips; unknown kind still errors.
- Capacity: total people <= 4 for every seed/difficulty.
- Time limit and reward formulas for 1-3 sites; medal thresholds reachable.

### Task 1: Points and people (pure)
**Files:** modify `rust/src/game/airgen.rs`, `missions.rs` (`nearest_landing`), tests `airgen_tests.rs`.
**Interfaces:** Produces `airgen::rescue_points(t:&Terrain, key:u64, difficulty:u8)->Vec<V3>` (sites then base), `airgen::rescue_people(seed:u64, sites:usize)->Vec<u8>`, `missions::landing_ok(t,p)->bool`.
- [ ] Tests (RED first): for seeds 1..=60 and difficulties 1..=3: `rescue_points` has `difficulty + 1` points, each `landing_ok` (point_ok and `normal.y >= 0.97`), not in water/city (implied), pairwise distance >= 60 m, deterministic; first point 150-600 m from the origin; `rescue_people(seed, n)` has n entries each 1..=3 and sum <= 4, deterministic.
- [ ] Implement: `landing_ok` = `point_ok(t, p) && t.normal(p.x,p.z).y >= 0.97`; `nearest_landing(t,x,z)` as `nearest_ok` but with `landing_ok` (rings of 15 m up to 450 m, falling back to `nearest_ok`). `rescue_points`: `n = difficulty.clamp(1,3)`; first site at angle `hash01(key,61,1)*TAU`, distance `200 + 300*hash01(key,61,2)` from the origin; site i at distance `150 + 250*h` and a random angle from the previous; base at `300 + 400*h` from the last site; every point through `nearest_landing` and clamped with `clampw`; if two points end closer than 60 m push the later one 120 m further along its angle and re-run `nearest_landing`. `rescue_people`: all 1, then for i in 0..n if sum < 4 and `hash01(seed,62,i) < 0.5` add one (max 3).
- [ ] `cargo test --lib`; commit `feat(game): rescue points and people`.

### Task 3: State machine (AirRun)
**Files:** `airrun.rs` + `airrun_tests.rs`, `run.rs` unchanged.
**Interfaces:** Produces `AirRun::rescue_loaded()->u8`, `rescue_progress()->f32` (0..1 of the current dwell), `rescue_pending()->Vec<(V3, u8)>` (sites not yet done with their people counts).
- [ ] Tests (scripted aircraft: `Aircraft::new(Heli, pos, 0.0)` with `status` set directly): boarding after 3 s landed inside 6 m of site 1; progress rises; leaving the circle or `Flying` resets it; a second site only counts after the first; `rescue_loaded` accumulates `rescue_people`; after all sites the base needs 2 s landed to pass (`Passed`, medal from `grade_cargo`); landing on the base before the sites does nothing; touchdown with vertical speed 6 m/s costs 24 integrity (`integrity == 76`), 2.5 m/s costs nothing; integrity <= 0 fails with `CargoDestroyed`; crash fails `Crashed`; time up fails `TimeUp`; `abandon` works; `next_index` = sites done, `total` = sites + 1; `target` = next site / base.
- [ ] Implement: fields `stop: usize, loaded: u8, dwell: f32, people: Vec<u8>, was_flying: bool, last_vy: f32`; in `update` for `MissionKind::Rescue`: track `last_vy = a.vel.y` while `Flying`; on the first frame `Landed` after `Flying` apply the integrity cost with `-last_vy`; if `Landed` and horizontal distance to `checkpoints[stop] <= 6.0` then `dwell += dt` else `dwell = 0`; at the site when `dwell >= 3.0` -> `loaded += people[stop]`, `stop += 1`, `dwell = 0`; at the base (`stop == sites`) when `dwell >= 2.0` -> `pass()`. Integrity check like Sling. `total()` = `checkpoints.len()` for rescue.
- [ ] `cargo test --lib`; commit `feat(game): rescue state machine`.
