# Prism scene (dispersion, rainbow caustics) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A built-in "Prism" scene where sunlight through a wall slit is split by a glass prism into a spectrum on the floor and a wall, and the prism shows coloured edges to the camera.

**Architecture:** Scenes already compile into the shader as constants (`scenegen.rs`). Add a `prism` shape, wavelength-dependent glass (`ior`, `dispersion`), a forward photon pass (sun to prism to floor/wall receivers, `atomicAdd` into fixed-point counters, resolved into an exponentially averaged f32 map read by the trace passes), and a hero-wavelength path for camera rays through dispersive glass.

**Tech Stack:** Rust (wgpu 24, naga validation in host tests), WGSL, Kotlin params tables, GitHub Actions desktop smoke run (lavapipe) for screenshots, phone test over `su`.

**Spec:** `docs/superpowers/specs/2026-10-10-prism-design.md`

## Global Constraints

- Scenes stay shader constants; a scene change recompiles trace and gi_trace (and the photon passes). No per-scene uniform arrays (15x slower on Adreno).
- Adreno rules: never pass the `P` uniform by value (use `has(F_X)`); never index arrays by a loop variable; each expensive function gets ONE call site (the driver inlines every call); no early device-lost risk: a single dispatch must stay well under 1 s.
- Refractive index: `n(l) = ior + 0.012 * dispersion * ((0.589 / l)^2 - 1)`, `l` in micrometres. Wavelengths 380..780 nm, sampled uniformly.
- Photon count per frame N = 65536; fixed-point scale 2^20; receivers at most 2, at most 256 x 256 cells each; EMA factor 0.15 (1.0 on `history_reset`).
- Scene ids: 0 Classic, 1 Sun room, 2 Materials, 3 Prism, 4 = user file (was 3). `params.json` max 4.
- Files: JSON scenes in `rust/scenes/`, format doc `docs/scenes.md`, bilingual README and CHANGELOG, commit trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Phone tests: short, one launch, `am force-stop` then Termux to the foreground as the last command; never when the user says the phone is in use.

## Review Focus

- A scene with a prism but no sun, or no receivers, loads and renders (no photon pass, no crash, no black frame).
- A receiver whose `u` and `v` are parallel (zero area) or `cells` of 0 or above 256 is rejected with a readable message.
- `dispersion: 0` glass behaves exactly like before (same result as the 1.7.0 glass sphere, no wavelength path).
- Night sky (`sky_kind` 2) turns the sun, hence the photons, off: no stale rainbow remains lit.
- Switching scenes back and forth does not leak buffers or keep an old caustic map visible.
- A prism rotated by `yaw` and `spin` shades and casts photons consistently (same local frame in SDF, occlusion and photon tracing).

```rust
//! Glass dispersion optics shared by the scene code and the tests (the shaders get the same maths as generated text).

/// Refractive index at `lambda_nm`; `dispersion` 1.0 is ordinary crown glass, 0 switches dispersion off.
pub fn ior(lambda_nm: f32, base: f32, dispersion: f32) -> f32 {
    let l = lambda_nm * 1e-3;
    base + 0.012 * dispersion * ((0.589 / l) * (0.589 / l) - 1.0)
}

fn lobe(l: f32, mu: f32, s1: f32, s2: f32) -> f32 {
    let t = (l - mu) / if l < mu { s1 } else { s2 };
    (-0.5 * t * t).exp()
}

/// Wyman, Sloan and Shirley's multi-lobe fit of the CIE 1931 observer, converted to linear sRGB (negatives clamped).
pub fn wavelength_rgb(l: f32) -> [f32; 3] {
    let x = 1.056 * lobe(l, 599.8, 37.9, 31.0) + 0.362 * lobe(l, 442.0, 16.0, 26.7) - 0.065 * lobe(l, 501.1, 20.4, 26.2);
    let y = 0.821 * lobe(l, 568.8, 46.9, 40.5) + 0.286 * lobe(l, 530.9, 16.3, 31.1);
    let z = 1.217 * lobe(l, 437.0, 11.8, 36.0) + 0.681 * lobe(l, 459.0, 26.0, 13.8);
    [
        (3.2406 * x - 1.5372 * y - 0.4986 * z).max(0.0),
        (-0.9689 * x + 1.8758 * y + 0.0415 * z).max(0.0),
        (0.0557 * x - 0.2040 * y + 1.0570 * z).max(0.0),
    ]
}

/// Per-channel factor that makes the mean of `wavelength_rgb` over a uniform 380..780 nm sample equal to 1 (white).
pub fn spectrum_norm() -> [f32; 3] {
    let n = 400;
    let mut s = [0.0f32; 3];
    for i in 0..n {
        let c = wavelength_rgb(380.0 + 400.0 * (i as f32 + 0.5) / n as f32);
        for j in 0..3 { s[j] += c[j]; }
    }
    [n as f32 / s[0], n as f32 / s[1], n as f32 / s[2]]
}

/// Total deviation (degrees) of a ray through a prism with apex angle `apex_deg`, index `n`, first-face incidence `incidence_deg`.
pub fn deviation_deg(apex_deg: f32, n: f32, incidence_deg: f32) -> f32 {
    let a = apex_deg.to_radians();
    let i1 = incidence_deg.to_radians();
    let r1 = (i1.sin() / n).asin();
    let r2 = a - r1;
    let i2 = (n * r2.sin()).asin();
    (i1 + i2 - a).to_degrees()
}

pub fn min_deviation_deg(apex_deg: f32, n: f32) -> f32 {
    let a = apex_deg.to_radians();
    (2.0 * (n * (a * 0.5).sin()).asin() - a).to_degrees()
}

/// WGSL for the shaders: `ior_l(lambda_nm, base, dispersion)` and `wavelength_rgb(lambda_nm)` (already normalised to a white mean).
pub fn spectrum_wgsl() -> String {
    let k = spectrum_norm();
    format!(
        "fn ior_l(l_nm: f32, base: f32, disp: f32) -> f32 {{\n  let l = l_nm * 0.001;\n  return base + 0.012 * disp * ((0.589 / l) * (0.589 / l) - 1.0);\n}}\n\
fn lobe_w(l: f32, mu: f32, s1: f32, s2: f32) -> f32 {{\n  let t = (l - mu) / select(s2, s1, l < mu);\n  return exp(-0.5 * t * t);\n}}\n\
fn wavelength_rgb(l: f32) -> vec3<f32> {{\n\
  let x = 1.056 * lobe_w(l, 599.8, 37.9, 31.0) + 0.362 * lobe_w(l, 442.0, 16.0, 26.7) - 0.065 * lobe_w(l, 501.1, 20.4, 26.2);\n\
  let y = 0.821 * lobe_w(l, 568.8, 46.9, 40.5) + 0.286 * lobe_w(l, 530.9, 16.3, 31.1);\n\
  let z = 1.217 * lobe_w(l, 437.0, 11.8, 36.0) + 0.681 * lobe_w(l, 459.0, 26.0, 13.8);\n\
  let c = vec3<f32>(3.2406 * x - 1.5372 * y - 0.4986 * z, -0.9689 * x + 1.8758 * y + 0.0415 * z, 0.0557 * x - 0.2040 * y + 1.0570 * z);\n\
  return max(c, vec3<f32>(0.0)) * vec3<f32>({:?}, {:?}, {:?});\n}}\n",
        k[0], k[1], k[2]
    )
}
```

```wgsl
// Equilateral prism, triangle in the local xy plane (apex up, centroid at the origin), extruded along z; yaw is a fixed
// angle about y, spin an extra rotation speed. side = triangle side, len = length along z.
fn prism_local(p: vec3<f32>, c: vec3<f32>, yaw: f32, spin: f32) -> vec3<f32> {
  return rot_y(p - c, yaw + P.time * spin);
}

const SQ3H: f32 = 0.8660254;

// max of the five face distances: exact inside, a safe lower bound outside
fn d_prism(p: vec3<f32>, c: vec3<f32>, side: f32, len: f32, yaw: f32, spin: f32, bound: f32) -> f32 {
  let bd = length(p - c) - bound;
  if (bd > 0.2) { return bd; }
  let q = prism_local(p, c, yaw, spin);
  let r = side * 0.28867513; // inradius = side / (2 * sqrt 3)
  let dl = dot(q.xy, vec2<f32>(-SQ3H, 0.5)) - r;
  let dr = dot(q.xy, vec2<f32>(SQ3H, 0.5)) - r;
  let db = -q.y - r;
  return max(max(dl, dr), max(db, abs(q.z) - len * 0.5));
}

// Ray against the prism in its local frame: (t_in, t_out, face index in, face index out); a miss has t_in > t_out.
// Faces: 0 left, 1 right, 2 base, 3 back cap (-z), 4 front cap (+z).
fn prism_clip(o: vec3<f32>, d: vec3<f32>, side: f32, len: f32) -> vec4<f32> {
  let r = side * 0.28867513;
  var tin = -1e9;
  var tout = 1e9;
  var fin = -1.0;
  var fout = -1.0;
  for (var k = 0; k < 5; k = k + 1) {
    var n = vec3<f32>(0.0);
    var off = r;
    if (k == 0) { n = vec3<f32>(-SQ3H, 0.5, 0.0); }
    if (k == 1) { n = vec3<f32>(SQ3H, 0.5, 0.0); }
    if (k == 2) { n = vec3<f32>(0.0, -1.0, 0.0); }
    if (k == 3) { n = vec3<f32>(0.0, 0.0, -1.0); off = len * 0.5; }
    if (k == 4) { n = vec3<f32>(0.0, 0.0, 1.0); off = len * 0.5; }
    let den = dot(n, d);
    let num = off - dot(n, o);
    if (abs(den) < 1e-8) {
      if (num < 0.0) { return vec4<f32>(1.0, -1.0, -1.0, -1.0); }
    } else {
      let t = num / den;
      if (den < 0.0) {
        if (t > tin) { tin = t; fin = f32(k); }
      } else {
        if (t < tout) { tout = t; fout = f32(k); }
      }
    }
  }
  return vec4<f32>(tin, tout, fin, fout);
}

fn prism_normal(face: f32) -> vec3<f32> {
  if (face < 0.5) { return vec3<f32>(-SQ3H, 0.5, 0.0); }
  if (face < 1.5) { return vec3<f32>(SQ3H, 0.5, 0.0); }
  if (face < 2.5) { return vec3<f32>(0.0, -1.0, 0.0); }
  if (face < 3.5) { return vec3<f32>(0.0, 0.0, -1.0); }
  return vec3<f32>(0.0, 0.0, 1.0);
}

fn occ_prism(ro: vec3<f32>, dir: vec3<f32>, tmax: f32, c: vec3<f32>, side: f32, len: f32, yaw: f32, spin: f32) -> bool {
  let a = yaw + P.time * spin;
  let c4 = prism_clip(rot_y(ro - c, a), rot_y(dir, a), side, len);
  return c4.y > max(c4.x, 0.0) && c4.x < tmax;
}
```

```rust
pub fn caustic_at_wgsl(sc: &SceneData, with_map: bool) -> String {
    let mut s = String::new();

        s.push_str("fn cmap_cell(off: u32, nu: u32, nv: u32, a: f32, b: f32) -> vec3<f32> {\n  // bilinear fetch between cell centres\n  let x = clamp(a * f32(nu) - 0.5, 0.0, f32(nu) - 1.0);\n  let y = clamp(b * f32(nv) - 0.5, 0.0, f32(nv) - 1.0);\n  let x0 = u32(floor(x));\n  let y0 = u32(floor(y));\n  let x1 = min(x0 + 1u, nu - 1u);\n  let y1 = min(y0 + 1u, nv - 1u);\n  let fx = x - floor(x);\n  let fy = y - floor(y);\n  let c00 = CMAP[off + y0 * nu + x0].xyz;\n  let c10 = CMAP[off + y0 * nu + x1].xyz;\n  let c01 = CMAP[off + y1 * nu + x0].xyz;\n  let c11 = CMAP[off + y1 * nu + x1].xyz;\n  return mix(mix(c00, c10, fx), mix(c01, c11, fx), fy);\n}\n");
```

```rust
        let _ = writeln!(s, "  {{\n    let den = dot({n}, d);\n    if (abs(den) > 1e-6) {{\n      let t = dot({o} - p, {n}) / den;\n      if (t > 1e-3 && t < best.y) {{\n        let q = p + d * t - {o};\n        let a = dot(q, {u}) / {uu};\n        let b = dot(q, {v}) / {vv};\n        if (a >= 0.0 && a < 1.0 && b >= 0.0 && b < 1.0) {{\n          let cx = min(u32(a * {nu}.0), {nu1}u);\n          let cy = min(u32(b * {nv}.0), {nv1}u);\n          best = vec2<f32>(f32({off}u + cy * {nu}u + cx), t);\n        }}\n      }}\n    }}\n  }}",
            n = v3(n), o = v3(r.origin), u = v3(r.u), v = v3(r.v), uu = f(dot(r.u, r.u)), vv = f(dot(r.v, r.v)),
            nu = r.cells[0], nv = r.cells[1], nu1 = r.cells[0] - 1, nv1 = r.cells[1] - 1, off = receiver_offset(sc, i));
    }
    s.push_str("  return best;\n}\n");
    s
}
```

`photon.wgsl` (static body; `rng`, `rnd`, `sample_cone`, `rot_y`, `occ_all`, `sun_rad`, `schlick`, `isect_sphere` come from the scene text):

```wgsl
@group(0) @binding(0) var<uniform> P: Params;
@group(0) @binding(1) var<storage, read_write> COUNTS: array<atomic<u32>>;

fn to_local(v: vec3<f32>) -> vec3<f32> { return rot_y(v, PR_YAW + P.time * PR_SPIN); }
fn to_world(v: vec3<f32>) -> vec3<f32> { return rot_y(v, -(PR_YAW + P.time * PR_SPIN)); }

@compute @workgroup_size(64, 1, 1)
fn main(@builtin(global_invocation_id) gid: vec3<u32>) {
  if (!has_sun()) { return; }
  rng = pcg(gid.x + P.seed * 747796405u);
  rng = pcg(rng ^ 2747636419u);
  let axis = -SUN_DIR;
  let d0 = sample_cone(axis, SUN_COS);
  // start on the disc perpendicular to the sun that covers the prism's bound sphere
  let b = make_basis(axis);
  let rr = PR_BOUND * sqrt(rnd());
  let ph = 6.2831853 * rnd();
  let start = PR_C - axis * (PR_BOUND * 1.5) + (b[0] * cos(ph) + b[1] * sin(ph)) * rr;
  let lam = 380.0 + 400.0 * rnd();
  let n = ior_l(lam, PR_IOR, PR_DISP);
  let f0 = (n - 1.0) / (n + 1.0);

  // trace in the prism's own frame
  var o = to_local(start - PR_C);
  var d = to_local(d0);
  let c4 = prism_clip(o, d, PR_SIDE, PR_LEN);
  if (!(c4.y > max(c4.x, 0.0)) || c4.x < 0.0) { return; }
  let nin = prism_normal(c4.z);
  if (rnd() < schlick(clamp(-dot(d, nin), 0.0, 1.0), f0 * f0)) { return; }
  o = o + d * c4.x - nin * 1e-4;
  d = refract(d, nin, 1.0 / n);
  var out_ok = false;
  for (var k = 0; k < 5; k = k + 1) {
    let c = prism_clip(o, d, PR_SIDE, PR_LEN);
    let nout = prism_normal(c.w);
    let pos = o + d * c.y;
    let cosi = dot(d, nout);
    let sint = n * sqrt(max(0.0, 1.0 - cosi * cosi));
    var refl = sint > 1.0;
    if (!refl) { refl = rnd() < schlick(sqrt(max(0.0, 1.0 - sint * sint)), f0 * f0); }
    if (refl) {
      d = reflect(d, nout);
      o = pos - nout * 1e-4;
    } else {
      d = refract(d, -nout, n);
      o = pos + nout * 2e-3;
      out_ok = true;
      break;
    }
  }
  if (!out_ok) { return; }
  let wo = to_world(o) + PR_C;
  let wd = to_world(d);
  let hit = rx_hit(wo, wd);
  if (hit.x < 0.0) { return; }
  // occluders between the prism and the receiver (glass boxes tint, the rest blocks)
  let tr = occ_all(wo, wd, hit.y - 0.004, -1);
  let omega = 2.0 * PI * (1.0 - SUN_COS);
  let beam_area = PI * PR_BOUND * PR_BOUND;
  let e_perp = sun_rad() * omega; // irradiance on a surface facing the sun
  let phi = e_perp * beam_area / PHOTONS * wavelength_rgb(lam) * tr;
  let idx = u32(hit.x) * 3u;
  atomicAdd(&COUNTS[idx], u32(phi.x * FIXED));
  atomicAdd(&COUNTS[idx + 1u], u32(phi.y * FIXED));
  atomicAdd(&COUNTS[idx + 2u], u32(phi.z * FIXED));
}
```

`caustic_resolve.wgsl`:

```wgsl
@group(0) @binding(0) var<uniform> P: Params;
@group(0) @binding(1) var<storage, read_write> COUNTS: array<atomic<u32>>;
@group(0) @binding(2) var<storage, read_write> MAP: array<vec4<f32>>;

@compute @workgroup_size(64, 1, 1)
fn main(@builtin(global_invocation_id) gid: vec3<u32>) {
  let i = gid.x;
  if (i >= TOTAL_CELLS) { return; }
  let r = f32(atomicExchange(&COUNTS[i * 3u], 0u));
  let g = f32(atomicExchange(&COUNTS[i * 3u + 1u], 0u));
  let b = f32(atomicExchange(&COUNTS[i * 3u + 2u], 0u));
  // photons per frame -> irradiance E (power / area), shading wants E / pi
  let e = vec3<f32>(r, g, b) / FIXED / cell_area(i) / PI;
  let a = select(0.15, 1.0, P.history_reset != 0u);
  MAP[i] = vec4<f32>(mix(MAP[i].xyz, e, a), 1.0);
}
```

Concretely `caustic_resolve(sc)` = `COMMON + "const PI: f32 = 3.14159265;\n" + photon_wgsl(sc) + body`, and `photon_wgsl` does not mention `PI`.
