# City (v2.3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v2.3: one or two procedural cities per level (terrain plateau, grid of streets, blocks, buildings, parks), solid buildings for the car and the aircraft, soft landing on roofs, a city renderer within a frame budget, and a quality-dependent draw radius.

**Architecture:** A pure-CPU `game::city` module (layout from the seed, buildings, grid queries, collision helpers) and a `Ground` trait (terrain or terrain-plus-roofs) used by `flight` and `sling`. `Terrain` carries the city sites and blends its height to a plateau inside them. The renderer builds city instances through a pure `raster::citygen` (culling, budget, shadow subset) and draws them through the existing instance pipeline with a facade flag in the colour alpha.

**Tech Stack:** Rust 2021, wgpu raster (existing), WGSL, Kotlin (one call).

**Spec:** `docs/superpowers/specs/2026-10-12-city-design.md`

## Global Constraints

- No new Cargo dependencies; gameplay modules never import wgpu and test on the host (`cd rust && cargo test --lib`).
- Determinism: a seed always yields the same cities and buildings (integer hash, f32 math).
- City numbers: 11 x 11 blocks, pitch 48 m, street 12 m, block 36 m, `half = 264` m; building height 4-90 m (`8 + 82 * falloff^2 * hash`, 15 % of the outskirts low 4-6 m); parks: every 7th block by hash and the central block; 1, 2 or 4 lots per block with a 2 m inset and a 2 m gap; plateau rim 100 m.
- Sites: one city if `hash < 0.6`, otherwise two; centre 600-1500 m from the origin, at least 200 m inside the world wall, a second city at least 800 m from the first; the origin plateau is never inside a city.
- Render numbers: draw radius 700 m (quality Low/Medium/High: 400/600/700), `MAX_INST` 16384, city share of the buffer at most 6000, shadow subset within 150 m, facade flag = colour alpha 3 (glow stays alpha 2).
- Buildings never change the terrain heightfield; car collisions are explicit (hull spheres of radius 1.0 at z = -1.4, 0, 1.4, height 0.5, restitution 0.2).
- The state array, the JNI mission API, profiles and all existing tests keep working; mission points must still pass their rules over 200 seeds.
- UI strings bilingual via `t(en, ru)`; docs EN+RU. Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Rulings vs the spec (decided while planning): (a) city sites choose the flattest of 12 hashed candidates (smallest spread of nine height samples) and `base_y` is the mean of those samples, so the plateau cliffs stay small; (b) `Terrain` stays `Copy` by storing `[Option<CitySite>; 2]`; (c) streets are 12 + 12 long strips and each block gets a slab tile (sidewalk) instead of separate sidewalk stripes; (d) the shadow subset is "city parts within 150 m of the camera" (the camera is within a few metres of the player); (e) quality radius reaches the renderer through a new `Native.gameQuality(level)` call.

## Review Focus

- Site search for extreme seeds (0, `u64::MAX`, many random): sites inside the wall margin, 800 m apart, never on the origin plateau, no NaN (Task 2).
- Plateau continuity: no steps or NaN across the rim; spawn plateau still flat; props and ground mission points stay out of cities (Task 2).
- Car collisions: 30 m/s into a wall (no tunnelling), corners, sliding along a wall, not stuck inside a box after a teleport/reset (Task 4).
- Aircraft: crash into walls and undersides, soft roof landing and take-off again, cargo resting on a roof (Tasks 3-4).
- Instance budget: never above `MAX_INST`, markers and vehicles always kept, city truncated nearest-first (Task 5).
- Facade shader validates in naga, does not disturb glow markers (alpha flags) (Task 5).

//! Procedural city: grid of streets and blocks, lots with buildings, parks, grid queries and collision helpers.
use std::collections::HashMap;

use super::math::{v3, Q, V3};
use super::terrain::hash01;

pub const BLOCKS: i32 = 11;
pub const PITCH: f32 = 48.0;
pub const STREET: f32 = 12.0;
pub const BLOCK: f32 = 36.0;
pub const HALF: f32 = BLOCKS as f32 * PITCH / 2.0;

#[derive(Clone, Copy, Debug, PartialEq)]
pub struct CitySite { pub centre: V3, pub half: f32 }

#[derive(Clone, Copy, Debug)]
pub struct Building { pub min: V3, pub max: V3, pub color: u8 }
impl Building {
    pub fn centre(&self) -> V3 { (self.min + self.max) * 0.5 }
    pub fn size(&self) -> V3 { self.max - self.min }
}

#[derive(Clone, Copy, Debug, PartialEq)] pub enum TileKind { Asphalt, Slab, Park }
#[derive(Clone, Copy, Debug)]
pub struct Tile { pub min_x: f32, pub min_z: f32, pub max_x: f32, pub max_z: f32, pub y: f32, pub kind: TileKind }

pub struct City { pub site: CitySite, pub buildings: Vec<Building>, pub tiles: Vec<Tile>, pub roofs: Vec<V3>, grid: HashMap<(i32, i32), Vec<usize>> }

impl City {
    pub fn build(site: CitySite, seed: u64) -> City {
        let key = seed ^ 0xC17;
        let (ox, oz, y0) = (site.centre.x - HALF, site.centre.z - HALF, site.centre.y);
        let inset = (PITCH - BLOCK) / 2.0;
        let mut buildings = Vec::new(); let mut tiles = Vec::new(); let mut roofs = Vec::new();
        // streets: BLOCKS + 1 strips each way
        for k in 0..=BLOCKS {
            let c = k as f32 * PITCH;
            tiles.push(Tile { min_x: ox + c - STREET / 2.0, max_x: ox + c + STREET / 2.0, min_z: oz, max_z: oz + 2.0 * HALF, y: y0, kind: TileKind::Asphalt });
            tiles.push(Tile { min_x: ox, max_x: ox + 2.0 * HALF, min_z: oz + c - STREET / 2.0, max_z: oz + c + STREET / 2.0, y: y0, kind: TileKind::Asphalt });
        }
        for j in 0..BLOCKS { for i in 0..BLOCKS {
            let (bx, bz) = (ox + i as f32 * PITCH + inset, oz + j as f32 * PITCH + inset);
            let h = hash01(key, i, j);
            let park = (i == BLOCKS / 2 && j == BLOCKS / 2) || h < 1.0 / 7.0;
            tiles.push(Tile { min_x: bx, max_x: bx + BLOCK, min_z: bz, max_z: bz + BLOCK, y: y0, kind: if park { TileKind::Park } else { TileKind::Slab } });
            if park { continue; }
            let (cx, cz) = (bx + BLOCK / 2.0, bz + BLOCK / 2.0);
            let falloff = (1.0 - (cx - site.centre.x).hypot(cz - site.centre.z) / (HALF * 1.2)).clamp(0.0, 1.0);
            // lots inside the block: 2 m inset, 2 m gap
            let lots: Vec<(f32, f32, f32, f32)> = {
                let (a, b, s) = (bx + 2.0, bz + 2.0, BLOCK - 4.0);
                let half = (s - 2.0) / 2.0;
                match (hash01(key ^ 1, i, j) * 3.0) as u32 {
                    0 => vec![(a, b, a + s, b + s)],
                    1 => if hash01(key ^ 2, i, j) < 0.5 { vec![(a, b, a + half, b + s), (a + half + 2.0, b, a + s, b + s)] } else { vec![(a, b, a + s, b + half), (a, b + half + 2.0, a + s, b + s)] },
                    _ => vec![(a, b, a + half, b + half), (a + half + 2.0, b, a + s, b + half), (a, b + half + 2.0, a + half, b + s), (a + half + 2.0, b + half + 2.0, a + s, b + s)],
                }
            };
            for (n, (x0, z0, x1, z1)) in lots.into_iter().enumerate() {
                let hh = hash01(key ^ 3, i * 4 + n as i32, j);
                let mut height = 8.0 + 82.0 * falloff * falloff * hh;
                if falloff < 0.35 && hash01(key ^ 4, i * 4 + n as i32, j) < 0.15 { height = 4.0 + 2.0 * hh; }
                let height = height.clamp(4.0, 90.0);
                buildings.push(Building { min: v3(x0, y0, z0), max: v3(x1, y0 + height, z1), color: (hash01(key ^ 5, i * 4 + n as i32, j) * 6.0) as u8 % 6 });
                if height >= 20.0 && x1 - x0 >= 14.0 && z1 - z0 >= 14.0 { roofs.push(v3((x0 + x1) / 2.0, y0 + height, (z0 + z1) / 2.0)); }
            }
        } }
        City::with(site, buildings, tiles, roofs)
    }

    pub fn from_buildings(site: CitySite, buildings: Vec<Building>) -> City { City::with(site, buildings, Vec::new(), Vec::new()) }

    fn with(site: CitySite, buildings: Vec<Building>, tiles: Vec<Tile>, roofs: Vec<V3>) -> City {
        let mut grid: HashMap<(i32, i32), Vec<usize>> = HashMap::new();
        let (ox, oz) = (site.centre.x - site.half, site.centre.z - site.half);
        for (idx, b) in buildings.iter().enumerate() {
            let (c0, c1) = (((b.min.x - ox) / PITCH).floor() as i32, ((b.max.x - ox) / PITCH).floor() as i32);
            let (r0, r1) = (((b.min.z - oz) / PITCH).floor() as i32, ((b.max.z - oz) / PITCH).floor() as i32);
            for r in r0..=r1 { for c in c0..=c1 { grid.entry((c, r)).or_default().push(idx); } }
        }
        City { site, buildings, tiles, roofs, grid }
    }

    fn cell(&self, x: f32, z: f32) -> (i32, i32) {
        (((x - (self.site.centre.x - self.site.half)) / PITCH).floor() as i32, ((z - (self.site.centre.z - self.site.half)) / PITCH).floor() as i32)
    }

    pub fn inside(&self, x: f32, z: f32) -> bool { (x - self.site.centre.x).abs() <= self.site.half && (z - self.site.centre.z).abs() <= self.site.half }

    pub fn roof_at(&self, x: f32, z: f32) -> Option<f32> {
        let c = self.cell(x, z);
        self.grid.get(&c)?.iter().map(|&i| &self.buildings[i]).find(|b| x >= b.min.x && x <= b.max.x && z >= b.min.z && z <= b.max.z).map(|b| b.max.y)
    }

    pub fn buildings_near(&self, p: V3, r: f32) -> Vec<&Building> {
        let (c0, r0) = self.cell(p.x - r, p.z - r); let (c1, r1) = self.cell(p.x + r, p.z + r);
        let mut seen: Vec<usize> = Vec::new();
        for row in r0..=r1 { for col in c0..=c1 { if let Some(v) = self.grid.get(&(col, row)) { for &i in v { if !seen.contains(&i) { seen.push(i); } } } } }
        seen.into_iter().map(|i| &self.buildings[i]).collect()
    }

    /// The centre of a street intersection chosen by `key`.
    pub fn street_point(&self, key: u64) -> V3 {
        let n = BLOCKS + 1;
        let i = (hash01(key, 7, 1) * n as f32) as i32 % n; let j = (hash01(key, 7, 2) * n as f32) as i32 % n;
        v3(self.site.centre.x - self.site.half + i as f32 * PITCH, self.site.centre.y, self.site.centre.z - self.site.half + j as f32 * PITCH)
    }

    /// Deepest overlap of a sphere with a building: (push-out vector, surface normal).
    pub fn push_out(&self, p: V3, r: f32) -> Option<(V3, V3)> {
        let mut best: Option<(f32, V3, V3)> = None;
        for b in self.buildings_near(p, r + 1.0) {
            let q = v3(p.x.clamp(b.min.x, b.max.x), p.y.clamp(b.min.y, b.max.y), p.z.clamp(b.min.z, b.max.z));
            let d = p - q; let dist = d.len();
            let (depth, normal) = if dist > 1e-5 {
                if dist >= r { continue; }
                (r - dist, d * (1.0 / dist))
            } else {
                // centre inside the box: leave through the nearest face
                let faces = [(p.x - b.min.x, v3(-1., 0., 0.)), (b.max.x - p.x, v3(1., 0., 0.)), (p.z - b.min.z, v3(0., 0., -1.)), (b.max.z - p.z, v3(0., 0., 1.)), (b.max.y - p.y, v3(0., 1., 0.))];
                let (pen, n) = faces.iter().cloned().fold((f32::MAX, V3::ZERO), |a, f| if f.0 < a.0 { f } else { a });
                (pen + r, n)
            };
            if best.map_or(true, |(bd, _, _)| depth > bd) { best = Some((depth, normal * depth, normal)); }
        }
        best.map(|(_, push, n)| (push, n))
    }

    pub fn touches_side(&self, p: V3, r: f32) -> bool {
        self.buildings_near(p, r + 1.0).into_iter().any(|b| {
            let q = v3(p.x.clamp(b.min.x, b.max.x), p.y.clamp(b.min.y, b.max.y), p.z.clamp(b.min.z, b.max.z));
            let d = p - q; let dist = d.len();
            if dist >= r { return false; }
            if dist < 1e-5 { return true; }
            (d.y / dist) < 0.7
        })
    }

//! Pure city instance builder: culling by radius, nearest-first order, a hard budget, and the shadow subset.
use super::models::Part;
use crate::game::city::{City, TileKind};
use crate::game::math::{v3, Q, V3};

pub const PALETTE: [[f32; 3]; 6] = [[0.62, 0.60, 0.57], [0.55, 0.30, 0.24], [0.45, 0.52, 0.60], [0.70, 0.66, 0.55], [0.38, 0.42, 0.48], [0.58, 0.62, 0.58]];

pub struct CityParts { pub parts: Vec<Part>, pub near: usize }

fn dist(p: &Part, cam: V3) -> f32 { (p.pos.x - cam.x).hypot(p.pos.z - cam.z) }

pub fn city_parts(cities: &[City], cam: V3, radius: f32, budget: usize, shadow_radius: f32) -> CityParts {
    let mut buildings: Vec<Part> = Vec::new(); let mut tiles: Vec<Part> = Vec::new();
    for c in cities {
        if !c.inside(cam.x, cam.z) && (cam.x - c.site.centre.x).abs().max((cam.z - c.site.centre.z).abs()) > c.site.half + radius { continue; }
        for b in &c.buildings {
            let (ctr, size) = (b.centre(), b.size());
            let p = Part { mesh: 0, rot: Q::IDENT, pos: ctr, scale: size, color: PALETTE[b.color as usize % 6], glow: false, facade: true };
            if dist(&p, cam) <= radius + size.x.max(size.z) { buildings.push(p); }
        }
        for t in &c.tiles {
            let (cx, cz) = ((t.min_x + t.max_x) * 0.5, (t.min_z + t.max_z) * 0.5);
            let (sx, sz) = (t.max_x - t.min_x, t.max_z - t.min_z);
            let (h, color) = match t.kind { TileKind::Asphalt => (0.1, [0.16, 0.16, 0.18]), TileKind::Slab => (0.25, [0.55, 0.55, 0.52]), TileKind::Park => (0.3, [0.22, 0.45, 0.20]) };
            let p = Part { mesh: 0, rot: Q::IDENT, pos: v3(cx, t.y + h * 0.5 + if t.kind == TileKind::Asphalt { 0.02 } else { 0.0 }, cz), scale: v3(sx, h, sz), color, glow: false, facade: false };
            if dist(&p, cam) <= radius + sx.max(sz) * 0.5 { tiles.push(p); }
        }
    }
    let by = |a: &Part, b: &Part| dist(a, cam).partial_cmp(&dist(b, cam)).unwrap_or(std::cmp::Ordering::Equal);
    buildings.sort_by(by); tiles.sort_by(by);
    let mut parts = buildings; parts.extend(tiles); parts.truncate(budget);
    let near = parts.iter().take_while(|p| dist(p, cam) <= shadow_radius + p.scale.x.max(p.scale.z)).count();
    CityParts { parts, near }
}
