> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v2.5: generated material maps and per-vertex material weights for the terrain, wheel tracks, a model pipeline with specular and sky reflection, and generated detailed models of the off-roader, helicopter and drone, with colours in `vehicles.json`.

**Architecture:** Pure-CPU generators (`raster::texgen`, `game::materials`, `game::tracks`, `raster::vehicle_models`) are tested on the host; the GPU side (`raster::gpu`, `raster.wgsl`) uploads the material array and model meshes and draws them through one new `model` pipeline; the terrain pipeline gains a per-vertex weight buffer and samples the texture array.

**Tech Stack:** Rust 2021, wgpu 24 (texture array, mips, one more pipeline), WGSL, serde_json (look parsing).

**Spec:** `docs/superpowers/specs/2026-10-12-graphics1-design.md`

## Global Constraints

- No new Cargo dependencies and no asset files: all textures and meshes are generated by code, deterministically (fixed seeds).
- Textures: 5 layers of 256 x 256 RGBA8 sRGB (grass, dirt, sand, rock, asphalt) with a full mip chain in one `texture_2d_array`; the sampler repeats, linear + mip linear, anisotropy 4.
- Terrain material weights are `[u8; 4]` (grass, dirt, sand, rock) summing to 255, computed per vertex on the CPU; the fragment shader samples 4 layers at `wp.xz / 6 m` plus one macro sample at `wp.xz / 40 m`.
- Tracks: ring buffer of 256 segments, one per 0.35 m per wheel in ground contact at speed > 2 m/s; none on rock-dominated ground.
- Model materials: 0 paint, 1 glass, 2 rubber, 3 plastic, 4 chrome, 5 emissive (id packed in the vertex colour alpha). Triangle limits: off-roader <= 4000, helicopter <= 2000, drone <= 1000. The car body width/length match `vehicles.json` `size` within 5 %.
- The model pipeline vertex is 28 bytes (position f32x3, normal f32x3, colour unorm8x4); instance = model matrix (4 x vec4) + tint vec4 (80 bytes); models also draw into the shadow map.
- `vehicles.json` gets an optional `look` section (colours in 0..1, `wheel_width`); physics numbers are untouched; the golden physics test and all existing tests keep passing.
- Quality: the phone must stay >= 60 fps on High (measured in Task 6, owner's permission needed).
- UI strings bilingual via `t(en, ru)`; docs EN+RU. Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Rulings vs the spec (decided while planning): (a) `VehicleSpec` gains `size: V3` (width, height, length) and both spec types gain `look: Look` so the renderer needs no extra lookups; (b) tile weights come from `Terrain::tile_mesh_with_weights` (skirt vertices copy their parents' weights); `tile_mesh` stays as a wrapper; (c) wheel spin is integrated in the renderer from the vehicle speed and frame time (no physics state); (d) markers, the rope, cargo and city instances keep the primitive instance pipeline; only vehicles use the model pipeline; (e) the blurred rotor disc of the spec is dropped (the rotor keeps spinning blades) to stay inside the frame budget.

```rust
//! Generated tileable material maps (RGBA8) and their mip chains. No files: everything comes from fixed seeds.
use crate::game::terrain::hash01;

pub const SIZE: usize = 256;
pub const LAYERS: usize = 5;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Material { Grass, Dirt, Sand, Rock, Asphalt }
impl Material { pub const ALL: [Material; 5] = [Material::Grass, Material::Dirt, Material::Sand, Material::Rock, Material::Asphalt]; }

fn smooth(t: f32) -> f32 { t * t * (3.0 - 2.0 * t) }

/// Value noise on a lattice of `period` x `period` cells that wraps around, so the result tiles.
fn tile_noise(seed: u64, x: f32, y: f32, period: i32) -> f32 {
    let (fx, fy) = (x.floor(), y.floor());
    let (ix, iy) = (fx as i32, fy as i32);
    let (u, v) = (smooth(x - fx), smooth(y - fy));
    let w = |a: i32, b: i32| hash01(seed, a.rem_euclid(period), b.rem_euclid(period));
    let top = w(ix, iy) + (w(ix + 1, iy) - w(ix, iy)) * u;
    let bot = w(ix, iy + 1) + (w(ix + 1, iy + 1) - w(ix, iy + 1)) * u;
    top + (bot - top) * v
}

/// Tileable fBm in 0..1 over the unit square (`x`, `y` in 0..1); `base` is the lattice period of the first octave.
fn fbm(seed: u64, x: f32, y: f32, base: i32, octaves: u32) -> f32 {
    let (mut sum, mut norm, mut amp, mut p) = (0.0, 0.0, 1.0, base);
    for o in 0..octaves { sum += amp * tile_noise(seed.wrapping_add(o as u64 * 977), x * p as f32, y * p as f32, p); norm += amp; amp *= 0.5; p *= 2; }
    sum / norm
}

pub fn make(m: Material, size: usize) -> Vec<u8> {
    let mut out = vec![255u8; size * size * 4];
    for py in 0..size { for px in 0..size {
        let (x, y) = (px as f32 / size as f32, py as f32 / size as f32);
        let broad = fbm(11, x, y, 4, 4);
        let fine = fbm(23, x, y, 32, 2);
        let col: [f32; 3] = match m {
            Material::Grass => { let t = (0.35 + 0.8 * broad) * (0.85 + 0.3 * fine); let tuft = (fbm(31, x, y, 64, 1) - 0.5) * 0.35; [0.26 * t + tuft * 0.2, 0.46 * t + tuft, 0.14 * t] }
            Material::Dirt => { let t = 0.55 + 0.7 * broad; let pebble = if fine > 0.78 { 0.18 } else { 0.0 }; [0.45 * t + pebble, 0.33 * t + pebble * 0.9, 0.21 * t + pebble * 0.7] }
            Material::Sand => { let ripple = (x * 18.0 * std::f32::consts::TAU + broad * 6.0).sin() * 0.04; let t = 0.85 + 0.3 * broad + ripple; [0.80 * t, 0.71 * t, 0.50 * t] }
            Material::Rock => { let strata = ((y * 6.0 * std::f32::consts::TAU + broad * 5.0).sin() * 0.5 + 0.5) * 0.35 + 0.65; let t = strata * (0.8 + 0.4 * fine); [0.47 * t, 0.45 * t, 0.42 * t] }
            Material::Asphalt => { let speck = if fine > 0.8 { 0.12 } else { 0.0 }; let t = 0.8 + 0.25 * broad; [0.17 * t + speck, 0.17 * t + speck, 0.18 * t + speck] }
        };
        let i = (py * size + px) * 4;
        for c in 0..3 { out[i + c] = (col[c].clamp(0.0, 1.0) * 255.0 + 0.5) as u8; }
    } }
    out
}

pub fn mips(level0: &[u8], size: usize) -> Vec<Vec<u8>> {
    let mut levels = vec![level0.to_vec()];
    let mut s = size;
    while s > 1 {
        let prev = levels.last().unwrap(); let n = s / 2;
        let mut next = vec![255u8; n * n * 4];
        for y in 0..n { for x in 0..n { for c in 0..3 {
            let at = |xx: usize, yy: usize| prev[(yy * s + xx) * 4 + c] as u32;
            next[(y * n + x) * 4 + c] = ((at(2 * x, 2 * y) + at(2 * x + 1, 2 * y) + at(2 * x, 2 * y + 1) + at(2 * x + 1, 2 * y + 1) + 2) / 4) as u8;
        } } }
        levels.push(next); s = n;
    }
    levels
}
```

```rust
//! Per-vertex ground material weights: grass, dirt, sand, rock (sum 255).
use super::math::V3;
use super::terrain::hash01;

fn smoothstep(a: f32, b: f32, x: f32) -> f32 { let t = ((x - a) / (b - a)).clamp(0.0, 1.0); t * t * (3.0 - 2.0 * t) }

/// Smooth value noise over 24 m cells.
fn patch_noise(x: f32, z: f32) -> f32 {
    let (u, v) = (x / 24.0, z / 24.0);
    let (fx, fz) = (u.floor(), v.floor()); let (ix, iz) = (fx as i32, fz as i32);
    let (a, b) = (u - fx, v - fz); let (a, b) = (a * a * (3.0 - 2.0 * a), b * b * (3.0 - 2.0 * b));
    let h = |i: i32, j: i32| hash01(0xD1, i, j);
    let top = h(ix, iz) + (h(ix + 1, iz) - h(ix, iz)) * a; let bot = h(ix, iz + 1) + (h(ix + 1, iz + 1) - h(ix, iz + 1)) * a;
    top + (bot - top) * b
}

fn raw(h: f32, n: V3, x: f32, z: f32) -> [f32; 4] {
    let rock = smoothstep(0.86, 0.74, n.y).max(smoothstep(32.0, 46.0, h) * 0.6).clamp(0.0, 1.0);
    let sand = (1.0 - rock) * smoothstep(-3.0, -7.0, h);
    let dirt_f = (smoothstep(0.55, 0.72, patch_noise(x, z)) * 0.8 + smoothstep(0.95, 0.86, n.y) * 0.5).clamp(0.0, 1.0);
    let dirt = (1.0 - rock - sand).max(0.0) * dirt_f;
    let grass = (1.0 - rock - sand - dirt).max(0.0);
    [grass, dirt, sand, rock]
}

pub fn terrain_weights(h: f32, normal: V3, x: f32, z: f32) -> [u8; 4] {
    let w = raw(h, normal, x, z);
    let total: f32 = w.iter().sum::<f32>().max(1e-6);
    let mut out = [0u8; 4];
    let mut acc = 0u32;
    for i in 0..4 { out[i] = (w[i] / total * 255.0).round() as u8; acc += out[i] as u32; }
    // fix rounding so the sum is exactly 255 (adjust the largest weight)
    let big = (0..4).max_by_key(|&i| out[i]).unwrap();
    out[big] = (out[big] as i32 + 255 - acc as i32).clamp(0, 255) as u8;
    out
}

pub fn rock_dominant(h: f32, normal: V3, x: f32, z: f32) -> bool { terrain_weights(h, normal, x, z)[3] > 128 }
```

```rust
//! Wheel tracks: a ring buffer of dark ground marks left by wheels in contact with the ground.
use super::materials::rock_dominant;
use super::math::{v3, V3};
use super::terrain::Terrain;
use super::vehicle::Vehicle;

pub const MAX_TRACKS: usize = 256;
pub const SPACING: f32 = 0.35;

#[derive(Clone, Copy, Debug)]
pub struct Track { pub pos: V3, pub dir: V3, pub normal: V3 }

pub struct Tracks { segs: Vec<Track>, head: usize, last: [Option<V3>; 4] }

impl Tracks {
    pub fn new() -> Tracks { Tracks { segs: Vec::new(), head: 0, last: [None; 4] } }
    pub fn len(&self) -> usize { self.segs.len() }
    pub fn iter(&self) -> impl Iterator<Item = &Track> { self.segs.iter() }

    pub fn update(&mut self, v: &Vehicle, t: &Terrain, _dt: f32) {
        let up = v.up();
        for w in 0..4 {
            if v.comp[w] <= 0.0 || v.vel.len() < 2.0 { self.last[w] = None; continue; }
            let s = &v.spec;
            let p = v.pos + v.rot.rotate(s.wheels[w]) - up * (s.rest + s.radius - v.comp[w]);
            let h = t.height(p.x, p.z); let n = t.normal(p.x, p.z);
            if rock_dominant(h, n, p.x, p.z) || t.in_city(p.x, p.z, 0.0) { self.last[w] = None; continue; }
            let q = v3(p.x, h + 0.03, p.z);
            match self.last[w] {
                Some(prev) if (q - prev).len() < SPACING => {}
                prev => {
                    let dir = prev.map(|pv| v3(q.x - pv.x, 0.0, q.z - pv.z).norm()).filter(|d| d.len() > 0.5).unwrap_or_else(|| { let f = v.forward(); v3(f.x, 0.0, f.z).norm() });
                    let seg = Track { pos: q, dir, normal: n };
                    if self.segs.len() < MAX_TRACKS { self.segs.push(seg); } else { self.segs[self.head] = seg; self.head = (self.head + 1) % MAX_TRACKS; }
                    self.last[w] = Some(q);
                }
            }
        }
    }
}
```

```wgsl
    let sh = shadow_at(i.wp, n);

    let nh = max(dot(n, h), 0.0);
    let fres = pow(1.0 - max(dot(n, v), 0.0), 3.0);
    let refl_dir = reflect(-v, n);
    let sky = sky_gradient(refl_dir);
    var albedo = i.col; var spec = 0.0; var refl = 0.0; var emi = 0.0;
    let mat = i32(i.mat + 0.5);
    if (mat == 0) { spec = pow(nh, 60.0) * 0.6; refl = 0.20 + 0.3 * fres; }
    else if (mat == 1) { spec = pow(nh, 120.0); refl = 0.45 + 0.4 * fres; albedo = albedo * 0.5; }
    else if (mat == 3) { spec = pow(nh, 20.0) * 0.12; refl = 0.05; }
    else if (mat == 4) { spec = pow(nh, 200.0) * 1.2; refl = 0.75; }
    else if (mat == 5) { emi = 1.0; }
    var c = shade(albedo, i.wp, n);
    c = c + vec3<f32>(1.0, 0.93, 0.80) * spec * ndl * 3.0 + sky * refl * (0.3 + 0.7 * sh) + albedo * emi * 1.6;
    return vec4<f32>(finish(c), 1.0);
}
```
