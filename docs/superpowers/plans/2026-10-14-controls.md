# Car Controls and Settings Implementation Plan (v2.9)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline).

**Goal:** steering wheel, pedals, tilt steering, settings screen and volume for the car.
**Architecture:** pure logic in `DriveMath.kt` (Kotlin, JVM-tested) and small Rust changes; custom views (`WheelView`, `PedalView`, `DriveControls`) wired into `GameActivity`; `SettingsActivity` for preferences.
**Tech Stack:** Kotlin Activities (no AndroidX), Rust JNI.
**Spec:** docs/superpowers/specs/2026-10-14-controls-design.md

## Global Constraints
- Car only; flight keeps sticks. No sliders. EN+RU strings. Version 2.9.0 (versionCode 20). Trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Device checks short, Termux in front at the end, never touch the user's profile.json; sound plays during device tests (warn at night).
- Unit tests: `./gradlew --no-daemon testDebugUnitTest -q`; Rust: `cargo test --lib`.

## Review Focus
- Multi-touch: wheel and pedals each follow their own pointer; a lifted or cancelled pointer always releases (no stuck throttle/brake/steer), activity pause releases everything.
- Brake/reverse switch at 3 km/h does not flap; reverse never starts while rolling forward fast.
- Tilt: orientation (landscape 90/270 rotation both directions), sensor unregistered in `onPause`, calibration, no steering while paused.
- Settings changes reaching a running game (sensitivity, side, mode, volume) without restart, quality applied next start.
- Safe defaults when preferences are missing or out of range.

### Task 1: Rust (analog brake, volume)
**Files:** `rust/src/game/input.rs`, `vehicle.rs`, `vehicle_tests.rs`, `game_jni.rs`, `rust/src/audio/{synth,mod,synth_tests}.rs`, `app/.../Native.kt`.
- [ ] Tests first: (a) vehicle: from 20 m/s with `brake: true, brake_amt: 0.3` the car is still faster after 1 s than with `brake_amt: 0.0` (full); `brake_amt: 1.0` equals the legacy full brake speed within 1%. (b) `merge_input(throttle, steer, brake, handbrake, brake_amt)` maps and sanitises (`brake_amt` NaN -> 0, clamp 0..1). (c) synth: `set_volume(0.0)` renders exact silence, `set_volume(0.5)` gives about half the RMS of volume 1 (within 5%), NaN/out-of-range clamps to 0..1, default volume 1.
- [ ] Implement: `Input.brake_amt: f32` (doc: 0 = legacy full brake); vehicle: `let kb = if inp.brake { if inp.brake_amt > 0.0 { inp.brake_amt.clamp(0.05, 1.0) } else { 1.0 } } else { 1.0 };` and `fx -= ... * kb` only for the `inp.brake` part (the handbrake keeps full force); `merge_input` gets the fifth argument; JNI `gameInput(throttle, steer, brake, handbrake, brakeAmt: jfloat)`, `audioVolume(jfloat)`; `Synth::set_volume(f32)` multiplying the output after the soft clip (smoothed with the 80 ms smoother), `audio::set_volume`; `Native.kt` declarations.
- [ ] `cargo test --lib`; commit `feat: analog brake and master volume`.

### Task 2: Pure Kotlin logic and preferences
**Files:** create `app/src/main/java/dev/starinin/rallynvx/DriveMath.kt`, `Controls.kt`, `app/src/test/java/dev/starinin/rallynvx/DriveMathTest.kt`.
**Interfaces:** Produces `DriveMath.{wheelAngleDeg(x,y,cx,cy), class Wheel(maxDeg=120f){ down(angle), move(angle), up(), step(dt), angle, steer(sens) }, pedal(y,h), brakeMap(pressure, kmh) -> Pair<Boolean(brake), Float(reverse throttle)> plus brakeAmt, class Tilt{ calibrate(roll), update(roll, dt, sens): Float }, SENS = floatArrayOf(0.7f, 1f, 1.4f), VOLUME = floatArrayOf(0f,.25f,.5f,.75f,1f)}`; `Controls` (SharedPreferences "prefs": `mode` 0/1, `sens` 0..2 default 1, `left` Boolean, `volume` 0..4 default 3, `hintWheel`, `hintTilt`, with coercion and getters/setters, `cycle` helpers).
- [ ] Tests (RED): `wheelAngleDeg` quadrants (right 0, up 90, left 180, down -90 with y up convention documented); `Wheel` accumulates deltas across the +-180 seam without jumping, clamps at +-120, `up()` then `step` returns to 0 at 400 deg/s and never overshoots, `steer` is monotonic, odd, 0 at 0, +-1 at the limit with sens 1.0, lower with 0.7, saturated with 1.4 earlier; `pedal` 0 outside, 0.15 at the top, 1.0 at the bottom, clamped; `brakeMap(0.6, 20f)` = brake true, amt 0.6, no reverse; `brakeMap(0.6, 1f)` = no brake, throttle -0.6; exactly 3.0 km/h reverses; `Tilt`: dead zone 3 deg gives 0, 15 deg gives about 0.5 at sens 1, 30+ clamps to 1, calibrate re-zeros, smoothing converges and never overshoots, NaN is 0; volume steps.
- [ ] Implement `DriveMath` and `Controls`; `./gradlew --no-daemon testDebugUnitTest -q`; commit `feat(app): driving math and control preferences`.
