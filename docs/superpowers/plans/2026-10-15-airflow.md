# Airflow around the car Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a prototype of the airflow in a box that moves with the car (GPU solver plus a host-tested CPU reference, voxel body, debug slice view, phone fps measurement).

**Architecture:** `game/airflow.rs` is the CPU reference (non-wrapping grid, inflow/outflow boundaries, BFECC advection, vorticity confinement, Jacobi projection) and the voxelizer; `shaders/airflow.wgsl` + `raster/airflow_gpu.rs` run the same algorithm on the GPU, copying the structure of `fluid_gpu.rs`; the result is shown as a side slice inset in a screen corner when `airflow.debug` is on. Nothing is allocated when it is off.

**Tech Stack:** Rust, wgpu compute (WGSL, 3D storage textures `Rgba16Float` / `R32Float`), naga validation test `shaders_validate`.

**Spec:** `docs/superpowers/specs/2026-10-15-airflow-design.md`

## Global Constraints

- Box in the car frame: x lateral, y up, z forward; defaults `nx=48 ny=24 nz=96`, `cell=0.25` (12 x 6 x 24 m); config block `airflow` in `rust/surfaces.json` (`cell`, `nx`, `ny`, `nz`, `iterations`, `substeps`, `confinement`, `debug`).
- Inflow at the front face (z max) is `-v_rel` in the car frame (car velocity minus wind, rotated by yaw); free outflow at the back; the ground (y below `ground`) is a solid moving at `-v_rel`.
- Success: wake visible in the slice and growing with speed; fps > 50 at 0.25 m on the POCO F3, else coarser cell noted in the spec; with `debug` off nothing is allocated; all existing tests stay green.
- Writing style: code like the surrounding files (dense, `///` docs, tests in `*_tests.rs`); bilingual docs; no sliders/UI changes.

## Review Focus

- Zero airspeed (car standing): inflow 0, the solver must stay at rest and not produce NaN.
- Very high speed or large dt: advection must clamp its back-trace to the box, no NaN.
- Car with all garage parts: voxel count only grows and stays inside the box.
- `debug` on a device that cannot use the storage formats: the feature turns itself off with one log line, the game runs.
- Config with a missing `airflow` block or a bad number: a clear error, like the `fluid` block.

```rust
/// The numbers of `surfaces.json` -> `airflow`.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct AirflowCfg { pub debug: bool, pub cell: f32, pub n: [usize; 3], pub iterations: u32, pub substeps: u32, pub confinement: f32 }

impl AirflowCfg {
    pub fn from_json(text: &str) -> Result<AirflowCfg, String> {
        let v: serde_json::Value = serde_json::from_str(text).map_err(|e| format!("surfaces file is not valid JSON: {e}"))?;
        let f = v.get("airflow").filter(|o| o.is_object()).ok_or("surfaces: missing object \"airflow\"")?;
        let num = |key: &str, lo: f64, hi: f64| -> Result<f32, String> {
            let x = f.get(key).and_then(|k| k.as_f64()).filter(|x| x.is_finite()).ok_or_else(|| format!("airflow: missing or non-numeric \"{key}\""))?;
            if x < lo || x > hi { return Err(format!("airflow: \"{key}\" must be between {lo} and {hi} (got {x})")); }
            Ok(x as f32)
        };
        let debug = f.get("debug").and_then(|d| d.as_f64()).map_or(false, |d| d > 0.5);
        Ok(AirflowCfg { debug, cell: num("cell", 0.1, 1.0)?, n: [num("nx", 8.0, 128.0)? as usize, num("ny", 8.0, 64.0)? as usize, num("nz", 16.0, 256.0)? as usize],
            iterations: num("iterations", 1.0, 64.0)? as u32, substeps: num("substeps", 1.0, 4.0)? as u32, confinement: num("confinement", 0.0, 2.0)? })
    }
}

pub fn cfg() -> AirflowCfg { AirflowCfg::from_json(super::grip::EMBEDDED).expect("the embedded surfaces.json has a bad airflow block") }
```

```rust
fn clampi(a: i32, n: usize) -> usize { a.clamp(0, n as i32 - 1) as usize }

pub struct Airflow {
    pub n: [usize; 3], pub dx: f32,
    pub vel: Vec<[f32; 3]>, pres: Vec<f32>, div: Vec<f32>,
    /// `Some(velocity)` where the cell is solid (the ground and the car).
    pub solid: Vec<Option<[f32; 3]>>,
    pub inflow: [f32; 3],
}

impl Airflow {
    pub fn new(n: [usize; 3], dx: f32) -> Airflow {
        let c = n[0] * n[1] * n[2];
        Airflow { n, dx, vel: vec![[0.0; 3]; c], pres: vec![0.0; c], div: vec![0.0; c], solid: vec![None; c], inflow: [0.0; 3] }
    }
    pub fn idx(&self, c: [i32; 3]) -> usize { (clampi(c[2], self.n[2]) * self.n[1] + clampi(c[1], self.n[1])) * self.n[0] + clampi(c[0], self.n[0]) }
    fn cells(&self) -> impl Iterator<Item = [i32; 3]> {
        let n = self.n;
        (0..n[2] as i32).flat_map(move |z| (0..n[1] as i32).flat_map(move |y| (0..n[0] as i32).map(move |x| [x, y, z])))
    }
    /// The air velocity coming at the car (in the car frame); the air in the box starts at it.
    pub fn set_inflow(&mut self, v: [f32; 3]) {
        self.inflow = v;
        for i in 0..self.vel.len() { if self.solid[i].is_none() && self.vel[i] == [0.0; 3] { self.vel[i] = v; } }
        for s in self.solid.iter_mut() { if s.is_some() && s.unwrap() != [0.0; 3] { *s = Some(v); } }
    }
    /// A solid box of cells `lo..hi` (the car; it does not move in its own frame).
    pub fn set_solid_box(&mut self, lo: [i32; 3], hi: [i32; 3]) {
        for c in self.cells().collect::<Vec<_>>() {
            if (0..3).all(|a| c[a] >= lo[a] && c[a] < hi[a]) { let i = self.idx(c); self.solid[i] = Some([0.0; 3]); self.vel[i] = [0.0; 3]; }
        }
    }
    /// The ground: cells with y < `rows` move with the road at the inflow velocity.
    pub fn set_ground(&mut self, rows: i32) {
        for c in self.cells().collect::<Vec<_>>() { if c[1] < rows { let i = self.idx(c); self.solid[i] = Some(self.inflow); self.vel[i] = self.inflow; } }
    }
    fn v_at(&self, c: [i32; 3]) -> [f32; 3] {
        if c[2] >= self.n[2] as i32 { return self.inflow; }   // beyond the front face: the incoming air
        let i = self.idx(c);
        self.solid[i].unwrap_or(self.vel[i])
    }
    fn sample(&self, f: &[[f32; 3]], p: [f32; 3]) -> [f32; 3] {
        let g = p.map(|v| v / self.dx - 0.5);
        let i = g.map(|v| v.floor());
        let t = [g[0] - i[0], g[1] - i[1], g[2] - i[2]];
        let c0 = [i[0] as i32, i[1] as i32, i[2] as i32];
        let at = |dx: i32, dy: i32, dz: i32| { let c = [c0[0] + dx, c0[1] + dy, c0[2] + dz]; if c[2] >= self.n[2] as i32 { self.inflow } else { f[self.idx(c)] } };
        let l = |a: [f32; 3], b: [f32; 3], t: f32| [0, 1, 2].map(|k| a[k] + (b[k] - a[k]) * t);
        let x00 = l(at(0, 0, 0), at(1, 0, 0), t[0]); let x10 = l(at(0, 1, 0), at(1, 1, 0), t[0]);
        let x01 = l(at(0, 0, 1), at(1, 0, 1), t[0]); let x11 = l(at(0, 1, 1), at(1, 1, 1), t[0]);
        l(l(x00, x10, t[1]), l(x01, x11, t[1]), t[2])
    }
    fn centre(&self, c: [i32; 3]) -> [f32; 3] { c.map(|v| (v as f32 + 0.5) * self.dx) }
    /// Back-trace of at most a few cells (large dt or speed must not throw the sample out of the box).
    fn trace(&self, p: [f32; 3], v: [f32; 3], dt: f32) -> [f32; 3] {
        let max = 4.0 * self.dx;
        let d = [0, 1, 2].map(|k| (v[k] * dt).clamp(-max, max));
        [p[0] - d[0], p[1] - d[1], p[2] - d[2]]
    }
    /// BFECC: forward, backward, then the error-corrected semi-Lagrangian advection of the velocity.
    fn advect(&mut self, dt: f32) {
        let old = self.vel.clone();
        let fwd: Vec<[f32; 3]> = self.cells().map(|c| { let i = self.idx(c); self.sample(&old, self.trace(self.centre(c), old[i], dt)) }).collect();
        let back: Vec<[f32; 3]> = self.cells().map(|c| { let i = self.idx(c); self.sample(&fwd, self.trace(self.centre(c), fwd[i], -dt)) }).collect();
        let corrected: Vec<[f32; 3]> = (0..old.len()).map(|i| [0, 1, 2].map(|k| old[i][k] + 0.5 * (old[i][k] - back[i][k]))).collect();
        for c in self.cells().collect::<Vec<_>>() {
            let i = self.idx(c);
            if let Some(s) = self.solid[i] { self.vel[i] = s; continue; }
            let mut v = self.sample(&corrected, self.trace(self.centre(c), old[i], dt));
            // keep it inside the range of the plain result to stay stable
            let plain = self.sample(&old, self.trace(self.centre(c), old[i], dt));
            for k in 0..3 { let m = 0.5 * old[i][k].abs().max(plain[k].abs()) + 1.0; v[k] = v[k].clamp(plain[k] - m, plain[k] + m); }
            self.vel[i] = v;
        }
    }
    /// Vorticity confinement: pushes the air around the vorticity maxima so the wake keeps its swirl.
    fn confine(&mut self, dt: f32, strength: f32) {
        if strength <= 0.0 { return; }
        let w: Vec<[f32; 3]> = self.cells().map(|c| {
            let g = |d: [i32; 3], a: usize| self.v_at([c[0] + d[0], c[1] + d[1], c[2] + d[2]])[a];
            let h = 2.0 * self.dx;
            [(g([0, 1, 0], 2) - g([0, -1, 0], 2) - g([0, 0, 1], 1) + g([0, 0, -1], 1)) / h,
             (g([0, 0, 1], 0) - g([0, 0, -1], 0) - g([1, 0, 0], 2) + g([-1, 0, 0], 2)) / h,
             (g([1, 0, 0], 1) - g([-1, 0, 0], 1) - g([0, 1, 0], 0) + g([0, -1, 0], 0)) / h]
        }).collect();
        let mag: Vec<f32> = w.iter().map(|v| (v[0] * v[0] + v[1] * v[1] + v[2] * v[2]).sqrt()).collect();
        let cells: Vec<[i32; 3]> = self.cells().collect();
        for c in cells {
            let i = self.idx(c);
            if self.solid[i].is_some() { continue; }
            let m = |d: [i32; 3]| mag[self.idx([c[0] + d[0], c[1] + d[1], c[2] + d[2]])];
            let grad = [(m([1, 0, 0]) - m([-1, 0, 0])), (m([0, 1, 0]) - m([0, -1, 0])), (m([0, 0, 1]) - m([0, 0, -1]))];
            let len = (grad[0] * grad[0] + grad[1] * grad[1] + grad[2] * grad[2]).sqrt();
            if len < 1e-5 { continue; }
            let nn = grad.map(|g| g / len);
            let f = [nn[1] * w[i][2] - nn[2] * w[i][1], nn[2] * w[i][0] - nn[0] * w[i][2], nn[0] * w[i][1] - nn[1] * w[i][0]];
            for k in 0..3 { self.vel[i][k] += f[k] * strength * self.dx * dt * mag[i].min(50.0); }
        }
    }
    fn project(&mut self, iterations: u32) {
        let cells: Vec<[i32; 3]> = self.cells().collect();
        for &c in &cells {
            let i = self.idx(c);
            if self.solid[i].is_some() { self.div[i] = 0.0; continue; }
            let g = |d: [i32; 3], a: usize| self.v_at([c[0] + d[0], c[1] + d[1], c[2] + d[2]])[a];
            self.div[i] = (g([1, 0, 0], 0) - g([-1, 0, 0], 0) + g([0, 1, 0], 1) - g([0, -1, 0], 1) + g([0, 0, 1], 2) - g([0, 0, -1], 2)) / (2.0 * self.dx);
        }
        let front = self.n[2] as i32 - 1;
        for _ in 0..iterations {
            let old = self.pres.clone();
            for &c in &cells {
                let i = self.idx(c);
                if self.solid[i].is_some() || c[2] == front { self.pres[i] = 0.0; continue; }
                let p = |d: [i32; 3]| { let n = [c[0] + d[0], c[1] + d[1], c[2] + d[2]]; if n[2] < 0 { 0.0 } else { let j = self.idx(n); if self.solid[j].is_some() { old[i] } else { old[j] } } };   // the back is open (pressure 0 beyond it)
                let sum = p([1, 0, 0]) + p([-1, 0, 0]) + p([0, 1, 0]) + p([0, -1, 0]) + p([0, 0, 1]) + p([0, 0, -1]);
                self.pres[i] = (sum - self.div[i] * self.dx * self.dx) / 6.0;
            }
        }
        let oldv = self.vel.clone();
        for &c in &cells {
            let i = self.idx(c);
            if self.solid[i].is_some() { continue; }
            let p = |d: [i32; 3]| { let n = [c[0] + d[0], c[1] + d[1], c[2] + d[2]]; if n[2] < 0 { 0.0 } else { let j = self.idx(n); if self.solid[j].is_some() { self.pres[i] } else { self.pres[j] } } };
            let g = [p([1, 0, 0]) - p([-1, 0, 0]), p([0, 1, 0]) - p([0, -1, 0]), p([0, 0, 1]) - p([0, 0, -1])];
            for a in 0..3 { self.vel[i][a] = oldv[i][a] - g[a] / (2.0 * self.dx); }
        }
    }
    /// One step: advect, confine, hold the incoming air at the front, project.
    pub fn step(&mut self, dt: f32, iterations: u32, confinement: f32) {
        self.advect(dt);
        self.confine(dt, confinement);
        let front = self.n[2] - 1;
        for y in 0..self.n[1] as i32 { for x in 0..self.n[0] as i32 { let i = self.idx([x, y, front as i32]); if self.solid[i].is_none() { self.vel[i] = self.inflow; } } }
        self.project(iterations);
    }
    pub fn max_divergence(&mut self) -> f32 {
        let cells: Vec<[i32; 3]> = self.cells().collect();
        let mut m = 0.0f32;
        for c in cells {
            let i = self.idx(c);
            if self.solid[i].is_some() || c[2] >= self.n[2] as i32 - 2 { continue; }
            let g = |d: [i32; 3], a: usize| self.v_at([c[0] + d[0], c[1] + d[1], c[2] + d[2]])[a];
            m = m.max(((g([1, 0, 0], 0) - g([-1, 0, 0], 0) + g([0, 1, 0], 1) - g([0, -1, 0], 1) + g([0, 0, 1], 2) - g([0, 0, -1], 2)) / (2.0 * self.dx)).abs());
        }
        m
    }
    pub fn speed_at(&self, c: [i32; 3]) -> f32 { let v = self.vel[self.idx(c)]; (v[0] * v[0] + v[1] * v[1] + v[2] * v[2]).sqrt() }
}
```
