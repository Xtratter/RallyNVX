# Render Mode A (Hybrid) Implementation Plan (v2.10)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline).

**Goal:** PCSS soft shadows, terrain ray shadows from a height atlas, SSAO, selectable mode with an optional auto fallback.
**Architecture:** pure `heightatlas` and `fallback` modules (host-tested), shader additions, a post pipeline (offscreen scene, AO, composite) in `raster/gpu.rs`, thin JNI/Kotlin settings.
**Tech Stack:** Rust, wgpu 24, WGSL, Kotlin.
**Spec:** docs/superpowers/specs/2026-10-14-hybrid-design.md

## Global Constraints
- No new dependencies (f16 conversion by hand). Raster mode must render exactly as before when Hybrid is off (same shader paths behind `u.mode.x`).
- Version 2.10.0 (versionCode 21). Trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Device checks short, Termux in front at the end, sound plays during device tests, never touch the user's profile.json; no CI screenshot waits.

## Review Focus
- Mode switching at run time and after resize: no leaked or stale targets, depth/scene texture sizes match the surface, no validation errors in logcat.
- Atlas coherence: tile (tx,tz) always lands in slot `(tx mod 8, tz mod 8)` with the lookup `uv = (x - 1) / 1024`; evicted/new-level slots never serve stale heights.
- Shader: loops bounded, no NaN from `normalize` of a zero xz sun component, sky pixels unaffected by AO, PCSS never brighter than the raster filter at contact.
- Auto fallback: off by default, no flapping, resets on restart.

### Task 1: Height atlas (pure)
**Files:** create `rust/src/raster/heightatlas.rs` (+`heightatlas_tests.rs`); modify `raster/mod.rs`.
**Interfaces:** Produces `heightatlas::{ATLAS_TILES: i32 = 8, TEXELS: usize = 64, EMPTY: f32 = -10000.0, f32_to_f16(f32)->u16, slot(tx,tz)->(u32,u32), heights_from_mesh(verts:&[[f32;6]], lod:u32)->Vec<f32> (64*64), HeightAtlas{ new(), put(tx,tz,&[f32])->SlotWrite, evict_missing(&HashSet<(i32,i32)>)->Vec<SlotWrite>, clear()->Vec<SlotWrite>, lookup(x,z)->f32 }, SlotWrite{ slot:(u32,u32), data: Vec<u16> }}`.
- [ ] Tests (RED first): `f32_to_f16` exact for 0, 1, -2.5, 1024, -10000 (compare with the known bit patterns 0x0000, 0x3C00, 0xC100, 0x6400, 0xF0E2) and monotonic over a sweep; `slot` for negative tiles (`slot(-1,-9) == (7, 7)`); `heights_from_mesh` of lod 0 on `Terrain::new(7)` tile (2,-3): texel (i,j) equals `terrain.height(tx*128 + i*2, tz*128 + j*2)` within 1e-3, lod 1 and lod 2 meshes upsample to within 0.6 m / 1.5 m of the lod 0 values on gentle ground (sample median error); `HeightAtlas::put` then `lookup` at the tile's world coordinates agrees with `Terrain::height` within 0.3 m for 200 random points (lod 0), tiles at (0,0) and (8,0) share a slot, the later `put` wins, `evict_missing` clears slots whose tile is not present and returns exactly those writes (data all `EMPTY` as f16), `lookup` outside any owned tile returns `EMPTY`, `clear` empties everything.
- [ ] Implement per the interface (the atlas keeps `owner: [[Option<(i32,i32)>; 8]; 8]` and the f32 heights, `lookup` mirrors the shader: ring slot, bilinear between texels with `(x - 1)/2` texel coordinates, returns `EMPTY` for unowned tiles).
- [ ] `cargo test --lib heightatlas`; commit `feat(raster): height atlas`.

### Task 2: Render mode logic (pure)
**Files:** create `rust/src/game/rendermode.rs` (+tests); modify `game/mod.rs`, `game/app.rs` (`fill_state` `[26]`,`[27]` are written by the glue in Task 5; here only the pure types).
**Interfaces:** Produces `RenderMode{Raster,Hybrid}`, `default_mode(quality_index:i32)->RenderMode` (High=2 -> Hybrid else Raster), `FallbackMonitor{ new(), update(&mut self, fps: f32, dt: f32, hybrid: bool, auto: bool) -> bool, reset() }`.
- [ ] Tests: `default_mode(2) == Hybrid`, 0/1/-1/99 Raster; the monitor never fires when `auto == false` or not hybrid; fires after 4 s of fps < 50 (8 samples at 0.5 s granularity, accumulating `dt`), a single sample >= 50 resets the count; a very low fps with huge `dt` still needs 4 s of accumulated time (a hitch counts as `dt` clamped to 1 s); NaN fps is ignored; after firing it does not fire again until `reset()`.
- [ ] Implement; commit `feat(game): render mode defaults and fallback monitor`.

### Task 3: Shader layers and atlas upload
**Files:** `rust/src/shaders/raster.wgsl`, `rust/src/raster/gpu.rs`.
- [ ] `Uni` gains `mode: [f32;4]` (x hybrid 0/1) and `cam_tile: [f32;4]` (tile x, z), size 288 -> 320 (WGSL `U` too). Binding 5 of the main bind group layout: `texture_2d<f32>` (filterable, fragment), the atlas (512x512 `R16Float`, `COPY_DST`, filled with `EMPTY`); sampled with `mat_smp` (repeat, linear).
- [ ] WGSL: `PCSS_TAPS` Poisson constants; `shadow_at` branches on `u.mode.x`: blocker search with `textureLoad(shadow_tex, coords, 0)`, penumbra, 16-tap `textureSampleCompareLevel` PCF; `terrain_h(x,z)` and `terrain_shadow(wp, sun)` per the spec; `shade()` uses `min(shadow_at(...), terrain_shadow(...))` and a fade by `smoothstep(0.0, 0.2, dot(n, sun))` for the terrain term. Raster path unchanged when `mode.x < 0.5`.
- [ ] `gpu.rs`: owns `atlas: HeightAtlas` and the texture; when a tile mesh is built (`tile_mesh_with_weights`) call `heights_from_mesh` and `atlas.put`, upload the `SlotWrite` with `queue.write_texture` (64x64 `R16Float`); after `tiles.retain`, `evict_missing` with the set of tile coordinates present (all LODs) and upload the clears; `cache_seed` change calls `clear()`; `cam_tile` uniform from the camera tile; `set_hybrid(bool)` sets `mode.x` (the post passes come in Task 4).
- [ ] `cargo test --lib` (includes the naga `shaders_validate` test), `bash tools/build-native.sh`; device check with `set_hybrid(true)` forced by an intent extra `hybrid` (debug) and screenshots at a low sun; commit `feat(raster): PCSS and terrain ray shadows`.

### Task 4: SSAO and the post pipeline
**Files:** `rust/src/shaders/raster.wgsl`, `rust/src/raster/gpu.rs`.
- [ ] Depth texture always `TEXTURE_BINDING`; post targets (`scene` = surface format colour `RENDER_ATTACHMENT|TEXTURE_BINDING`, `ao` = `R8Unorm` at half size) created on `set_hybrid(true)` and on resize while hybrid, dropped on `set_hybrid(false)`.
- [ ] WGSL: `vs_full` (fullscreen triangle), `fs_ao` (depth `textureLoad`, world position through `inv_vp`, normal from neighbouring depths, 12 hemisphere samples radius 1.5 m with a range check and per-pixel rotation from a hash, output 1 - occlusion), `fs_post` (4-tap depth-aware upsample of `ao`, multiplies the `scene` colour by `mix(1, ao, 0.85)`, sky pixels (depth == 1) untouched). Bindings in `@group(1)`; the pipelines use the layout `[bgl_main, bgl_post]`.
- [ ] `render()`: in hybrid the main pass targets `scene` and stores the depth; then the AO pass, then the composite to the swapchain; raster mode unchanged.
- [ ] Build; device screenshots in both modes and fps at High (city, lake, forest); commit `feat(raster): SSAO and the hybrid post pipeline`.
