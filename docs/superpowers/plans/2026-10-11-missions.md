> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v2.1: a mission list (cargo delivery and checkpoint race) with a state machine, medals and money, a saved profile, marker rendering, and the Android menu, briefing, HUD, pause and results screens.

**Architecture:** Pure-CPU modules `game::{medals, missions, run, meta, api}` (host-tested, no wgpu). `World` optionally owns a `MissionRun` and exposes `markers()`; the raster renderer draws markers through its existing instance lists; `game::app::Game` records results and fills a 64-float state array that Kotlin polls through JNI; two stateless JNI helpers give the menu its mission list.

**Tech Stack:** Rust 2021, serde_json (already a dependency; no serde derive), wgpu (existing raster), Kotlin Activities with the M3 ui-kit.

**Spec:** `docs/superpowers/specs/2026-10-11-missions-design.md`

## Global Constraints

- No new Cargo dependencies.
- Gameplay modules must not import wgpu; they compile and test on the host (`cd rust && cargo test --lib`).
- All timing comes from the `dt` passed in (fixed 1/60 s steps), never the wall clock, so runs are deterministic.
- Level seeds are 24-bit (`game::app::level_seed`); mission seeds, profile seed all pass through it.
- Mission constants: goal radius 6 m; `time_limit = 1.6 * length_m / 12 + 20`; `reward_base = (100 + 0.15 * length_m) * {1.0, 1.4, 1.9}[difficulty-1]`; medal multipliers Bronze 1.0 / Silver 1.5 / Gold 2.2.
- Cargo damage: impact `(dv - 6) * 2.5` when horizontal speed change per step `dv > 6`; landing `(|vy| - 7) * 3` after more than 0.4 s airborne with `vy < -7`; flipped 8 per second; reset 5. Race missions take no damage.
- Profile file is atomic-written; corrupt or newer-version files are moved to `*.bak`, never overwritten silently.
- UI strings bilingual via `t(en, ru)`; docs EN+RU.
- The Scenes mode and all existing tests keep passing.
- Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Rulings vs the spec (decided while planning): (a) `MissionRun` yields the medal only; the money payout (which depends on the best earlier medal) is computed by `Profile::record`; (b) impact damage uses the **horizontal** velocity change, vertical landings are handled by the landing rule (avoids double counting); (c) the reachability rule is "no 10 m step of the straight line rises or falls more than 8 m" (the spec's 40 m would never trigger); (d) the existing `StartActivity` becomes the main menu (no new launcher activity); (e) the menu fetches missions through a stateless JNI call before any game surface exists.

## Review Focus

- Corrupt, empty, truncated or newer-version `profile.json`: app starts with a fresh profile, old file kept as `.bak` (Task 4).
- Mission goals on bad terrain: every generated point passes slope, prop-distance and world-limit rules over many seeds, and `roll` never panics for any `(profile_seed, round)` incl. 0 and `u32::MAX` (Task 2).
- Timer/damage edge cases: exactly-at-threshold values, damage taken after the run is done, time-up and goal in the same step, reset spam (Task 3).
- Pause and resume: no catch-up burst of physics steps after a pause (Task 6).
- Activity lifecycle: leaving the game screen mid-mission (Home, back) must not record a pass, and the profile must not be corrupted by a write during teardown (Tasks 6, 7).

```rust
//! Medal grading and money for finished missions (pure functions).
#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord)]
pub enum Medal { None = 0, Bronze = 1, Silver = 2, Gold = 3 }

impl Medal {
    pub fn from_u8(v: u8) -> Medal { match v { 1 => Medal::Bronze, 2 => Medal::Silver, 3 => Medal::Gold, _ => Medal::None } }
}

fn by_time(t: f32, limit: f32) -> Medal {
    if t <= 0.6 * limit { Medal::Gold } else if t <= 0.8 * limit { Medal::Silver } else { Medal::Bronze }
}

pub fn grade_cargo(t: f32, limit: f32, integrity: f32) -> Medal {
    let by_t = by_time(t, limit);
    let by_i = if integrity >= 90.0 { Medal::Gold } else if integrity >= 60.0 { Medal::Silver } else { Medal::Bronze };
    by_t.min(by_i)
}

pub fn grade_race(t: f32, limit: f32) -> Medal { by_time(t, limit) }

fn mult(m: Medal) -> f32 { match m { Medal::None => 0.0, Medal::Bronze => 1.0, Medal::Silver => 1.5, Medal::Gold => 2.2 } }

pub fn reward(base: f32, m: Medal) -> u32 { (base * mult(m)).round() as u32 }

/// Money for finishing with `new` when the best earlier medal for this mission was `best_before`.
pub fn payout(base: f32, new: Medal, best_before: Medal) -> u32 {
    if new > best_before { reward(base, new) - reward(base, best_before) } else { (reward(base, new) as f32 * 0.5).round() as u32 }
}
```

```rust
//! Mission model and deterministic generation of the mission list.
use super::app::level_seed;
use super::math::{v3, V3};
use super::props::tile_props;
use super::terrain::{hash01, Terrain};
use super::world::{tile_of, WORLD_LIMIT};

pub const GOAL_RADIUS: f32 = 6.0;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum MissionKind { Cargo, Race }

#[derive(Clone, Debug)]
pub struct Mission {
    pub kind: MissionKind, pub seed: u64, pub difficulty: u8,
    pub start: V3, pub goal: V3, pub checkpoints: Vec<V3>,
    pub length_m: f32, pub time_limit: f32, pub reward_base: f32,
}

pub fn path_length(start: V3, pts: &[V3]) -> f32 {
    let mut prev = start; let mut sum = 0.0;
    for p in pts { sum += (*p - prev).len(); prev = *p; }
    sum
}
pub fn time_limit_for(len: f32) -> f32 { 1.6 * len / 12.0 + 20.0 }
pub fn reward_base_for(len: f32, difficulty: u8) -> f32 {
    let f = match difficulty { 1 => 1.0, 2 => 1.4, _ => 1.9 };
    (100.0 + 0.15 * len) * f
}

/// A mission point must be on gentle ground (normal.y >= 0.94), clear of props (8 m) and inside the world wall.
pub fn point_ok(t: &Terrain, p: V3) -> bool {
    if p.x.abs() > WORLD_LIMIT - 40.0 || p.z.abs() > WORLD_LIMIT - 40.0 { return false; }
    if t.normal(p.x, p.z).y < 0.94 { return false; }
    let (tx, tz) = (tile_of(p.x), tile_of(p.z));
    for dz in -1..=1 { for dx in -1..=1 { for pr in tile_props(t, tx + dx, tz + dz) {
        if (pr.pos.x - p.x).hypot(pr.pos.z - p.z) < 8.0 + pr.radius { return false; }
    } } }
    true
}

/// No 10 m step of the straight line a->b rises or falls more than 8 m (rough reachability check).
pub fn line_ok(t: &Terrain, a: V3, b: V3) -> bool {
    let len = (b - a).len(); let n = (len / 10.0).ceil().max(1.0) as i32;
    let mut prev = t.height(a.x, a.z);
    for i in 1..=n {
        let k = i as f32 / n as f32;
        let h = t.height(a.x + (b.x - a.x) * k, a.z + (b.z - a.z) * k);
        if (h - prev).abs() > 8.0 { return false; }
        prev = h;
    }
    true
}

fn at(t: &Terrain, x: f32, z: f32) -> V3 { v3(x, t.height(x, z), z) }

/// Tries up to 20 goal candidates; returns the first fully valid one, else the one with fewest violations.
fn pick_goal(t: &Terrain, key: u64, difficulty: u8) -> V3 {
    let (dmin, dmax) = match difficulty { 1 => (400.0, 800.0), 2 => (700.0, 1100.0), _ => (1000.0, 1500.0) };
    let origin = at(t, 0.0, 0.0);
    let mut best = (u32::MAX, origin);
    for k in 0..20i32 {
        let a = hash01(key, k, 1) * std::f32::consts::TAU;
        let d = dmin + (dmax - dmin) * hash01(key, k, 2);
        let p = at(t, a.cos() * d, a.sin() * d);
        let bad = (!point_ok(t, p)) as u32 + (!line_ok(t, origin, p)) as u32;
        if bad == 0 { return p; }
        if bad < best.0 { best = (bad, p); }
    }
    best.1
}

/// Race checkpoints along start->goal with a lateral zigzag of at most 80 m; each point nudged sideways until valid.
fn race_points(t: &Terrain, key: u64, goal: V3) -> Vec<V3> {
    let n = 5 + (hash01(key, 7, 7) * 4.0) as usize % 4; // 5..=8
    let dir = v3(goal.x, 0.0, goal.z).norm();
    let side = v3(-dir.z, 0.0, dir.x);
    let mut out = Vec::new();
    for i in 1..n {
        let k = i as f32 / n as f32;
        let zig = if i % 2 == 0 { 1.0 } else { -1.0 } * 80.0 * hash01(key, 100 + i as i32, 3);
        let mut chosen = at(t, goal.x * k + side.x * zig, goal.z * k + side.z * zig);
        for j in 0..8 {
            let off = (j as f32 / 2.0).ceil() * 20.0 * if j % 2 == 0 { 1.0 } else { -1.0 };
            let p = at(t, goal.x * k + side.x * (zig + off), goal.z * k + side.z * (zig + off));
            if point_ok(t, p) { chosen = p; break; }
        }
        out.push(chosen);
    }
    out.push(goal);
    out
}

pub fn roll(profile_seed: u64, round: u32, gold_medals: u32) -> Vec<Mission> {
    let kinds = [MissionKind::Cargo, MissionKind::Race, MissionKind::Cargo, MissionKind::Race];
    kinds.iter().enumerate().map(|(slot, &kind)| {
        let key = profile_seed ^ ((round as u64) << 20) ^ ((slot as u64 + 1) * 0x9E37_79B9);
        let seed = level_seed(key.wrapping_mul(0x2545_F491_4F6C_DD1D) >> 8);
        let r = hash01(key, slot as i32, 9);
        let difficulty = if gold_medals >= 3 { 1 + (r * 3.0) as u8 % 3 } else { 1 + (r * 2.0) as u8 % 2 };
        let t = Terrain::new(seed);
        let goal = pick_goal(&t, key, difficulty);
        let checkpoints = if kind == MissionKind::Race { race_points(&t, key, goal) } else { vec![goal] };
        let start = at(&t, 0.0, 0.0);
        let length_m = path_length(start, &checkpoints);
        Mission { kind, seed, difficulty, start, goal, checkpoints, length_m,
            time_limit: time_limit_for(length_m), reward_base: reward_base_for(length_m, difficulty) }
    }).collect()
}
```

```rust
//! State machine of one mission attempt: timer, cargo integrity, checkpoints, outcome. No wall clock.
use super::input::Input;
use super::math::V3;
use super::medals::{grade_cargo, grade_race, Medal};
use super::missions::{Mission, MissionKind, GOAL_RADIUS};
use super::vehicle::Vehicle;

#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum Phase { Ready, Running, Done }
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum Failure { TimeUp, CargoDestroyed, Abandoned }
#[derive(Clone, Copy, Debug, PartialEq)]
pub enum Outcome { Passed { medal: Medal, time: f32, integrity: f32 }, Failed(Failure) }

pub struct MissionRun {
    m: Mission, phase: Phase, time: f32, integrity: f32, next: usize,
    prev_vel: V3, air_time: f32, outcome: Option<Outcome>, first: bool,
}

impl MissionRun {
    pub fn new(m: Mission) -> MissionRun {
        MissionRun { m, phase: Phase::Ready, time: 0.0, integrity: 100.0, next: 0, prev_vel: V3::ZERO, air_time: 0.0, outcome: None, first: true }
    }
    pub fn phase(&self) -> Phase { self.phase }
    pub fn outcome(&self) -> Option<Outcome> { self.outcome }
    pub fn time(&self) -> f32 { self.time }
    pub fn time_left(&self) -> f32 { (self.m.time_limit - self.time).max(0.0) }
    pub fn integrity(&self) -> f32 { self.integrity }
    pub fn next_index(&self) -> usize { self.next }
    pub fn mission(&self) -> &Mission { &self.m }
    pub fn target(&self) -> Option<V3> { if self.phase == Phase::Done { None } else { self.m.checkpoints.get(self.next).copied() } }

    pub fn abandon(&mut self) {
        if self.phase != Phase::Done { self.finish(Outcome::Failed(Failure::Abandoned)); }
    }

    fn finish(&mut self, o: Outcome) { self.phase = Phase::Done; self.outcome = Some(o); }

    pub fn update(&mut self, v: &Vehicle, inp: &Input, reset_pressed: bool, dt: f32) {
        if self.phase == Phase::Done { return; }
        if self.phase == Phase::Ready {
            if inp.throttle.abs() > 0.05 { self.phase = Phase::Running; } else { self.prev_vel = v.vel; self.first = false; return; }
        }
        self.time += dt;
        let cargo = self.m.kind == MissionKind::Cargo;
        if cargo {
            if !self.first {
                let (dx, dz) = (v.vel.x - self.prev_vel.x, v.vel.z - self.prev_vel.z);
                let dv = dx.hypot(dz);
                if dv > 6.0 { self.integrity -= (dv - 6.0) * 2.5; }
            }
            if v.contacts == 0 { self.air_time += dt; } else {
                if self.air_time > 0.4 && self.prev_vel.y < -7.0 { self.integrity -= (-self.prev_vel.y - 7.0) * 3.0; }
                self.air_time = 0.0;
            }
            if v.flipped() { self.integrity -= 8.0 * dt; }
            if reset_pressed { self.integrity -= 5.0; }
        }
        self.first = false;
        self.prev_vel = v.vel;
        // goal first: reaching it in the step the clock runs out still counts
        if let Some(p) = self.m.checkpoints.get(self.next) {
            if (v.pos - *p).len() <= GOAL_RADIUS && (cargo && self.integrity > 0.0 || !cargo) {
                self.next += 1;
                if self.next >= self.m.checkpoints.len() {
                    let medal = if cargo { grade_cargo(self.time, self.m.time_limit, self.integrity) } else { grade_race(self.time, self.m.time_limit) };
                    self.finish(Outcome::Passed { medal, time: self.time, integrity: self.integrity.max(0.0) });
                    return;
                }
            }
        }
        if cargo && self.integrity <= 0.0 { self.integrity = 0.0; self.finish(Outcome::Failed(Failure::CargoDestroyed)); return; }
        if self.time > self.m.time_limit { self.finish(Outcome::Failed(Failure::TimeUp)); }
    }
}

/// Angle to `to` relative to the heading (hx, hz) as seen from above: 0 ahead, positive = to the right.
/// With x right-handed (x left of a car heading +z), the right-hand side of heading h is (-hz, hx).
pub fn bearing(hx: f32, hz: f32, from: V3, to: V3) -> f32 {
    let (dx, dz) = (to.x - from.x, to.z - from.z);
    let fwd = hx * dx + hz * dz;
    let right = -hz * dx + hx * dz;
    right.atan2(fwd)
}
```

```rust
//! Player profile: money, mission results, saved as JSON (atomic write, corrupt files kept as .bak).
use std::path::Path;
use serde_json::{json, Value};

use super::medals::{payout, Medal};
use super::missions::{Mission, MissionKind};

pub const PROFILE_VERSION: u32 = 1;

#[derive(Clone, Debug)]
pub struct MissionResult { pub seed: u64, pub kind: MissionKind, pub medal: Medal, pub best_time: f32 }

#[derive(Clone, Debug)]
pub struct Profile { pub version: u32, pub money: u32, pub profile_seed: u64, pub round: u32, pub results: Vec<MissionResult> }

fn kind_id(k: MissionKind) -> u64 { if k == MissionKind::Cargo { 0 } else { 1 } }

impl Profile {
    pub fn new(seed: u64) -> Profile { Profile { version: PROFILE_VERSION, money: 0, profile_seed: seed, round: 0, results: Vec::new() } }

    pub fn to_json(&self) -> String {
        let results: Vec<Value> = self.results.iter().map(|r| json!({ "seed": r.seed, "kind": kind_id(r.kind), "medal": r.medal as u8, "best_time": r.best_time })).collect();
        serde_json::to_string_pretty(&json!({ "version": self.version, "money": self.money, "profile_seed": self.profile_seed, "round": self.round, "results": results })).unwrap()
    }

    pub fn from_json(s: &str) -> Result<Profile, String> {
        let v: Value = serde_json::from_str(s).map_err(|e| e.to_string())?;
        let num = |k: &str| v.get(k).and_then(Value::as_u64).ok_or_else(|| format!("bad field {k}"));
        let version = num("version")?;
        if version > PROFILE_VERSION as u64 { return Err(format!("profile version {version} is newer than {PROFILE_VERSION}")); }
        let money = u32::try_from(num("money")?).map_err(|_| "money out of range".to_string())?;
        let round = u32::try_from(num("round")?).map_err(|_| "round out of range".to_string())?;
        let profile_seed = num("profile_seed")?;
        let mut results = Vec::new();
        for r in v.get("results").and_then(Value::as_array).ok_or("bad results")? {
            let seed = r.get("seed").and_then(Value::as_u64).ok_or("bad result seed")?;
            let kind = match r.get("kind").and_then(Value::as_u64) { Some(0) => MissionKind::Cargo, Some(1) => MissionKind::Race, _ => return Err("bad result kind".into()) };
            let medal = Medal::from_u8(r.get("medal").and_then(Value::as_u64).unwrap_or(0).min(3) as u8);
            let best_time = r.get("best_time").and_then(Value::as_f64).unwrap_or(0.0) as f32;
            results.push(MissionResult { seed, kind, medal, best_time });
        }
        Ok(Profile { version: PROFILE_VERSION, money, profile_seed, round, results })
    }

    pub fn best_medal(&self, seed: u64, kind: MissionKind) -> Medal {
        self.results.iter().find(|r| r.seed == seed && r.kind == kind).map_or(Medal::None, |r| r.medal)
    }
    pub fn gold_count(&self) -> u32 { self.results.iter().filter(|r| r.medal == Medal::Gold).count() as u32 }

    /// Records a finished mission; returns the money paid (also added to `money`, saturating).
    pub fn record(&mut self, m: &Mission, medal: Medal, time: f32) -> u32 {
        let before = self.best_medal(m.seed, m.kind);
        let pay = payout(m.reward_base, medal, before);
        self.money = self.money.saturating_add(pay);
        match self.results.iter_mut().find(|r| r.seed == m.seed && r.kind == m.kind) {
            Some(r) => { if medal > r.medal { r.medal = medal; } if r.best_time == 0.0 || time < r.best_time { r.best_time = time; } }
            None => self.results.push(MissionResult { seed: m.seed, kind: m.kind, medal, best_time: time }),
        }
        pay
    }

    /// Writes to `<path>.tmp` then renames over `path`.
    pub fn save(&self, path: &Path) -> std::io::Result<()> {
        if let Some(d) = path.parent() { std::fs::create_dir_all(d)?; }
        let tmp = path.with_extension("json.tmp");
        std::fs::write(&tmp, self.to_json())?;
        std::fs::rename(&tmp, path)
    }

    /// Missing file: a fresh profile (saved). Unreadable or newer file: moved to `.bak`, then a fresh profile.
    pub fn load_or_new(path: &Path, fresh_seed: u64) -> Profile {
        match std::fs::read_to_string(path) {
            Ok(text) => match Profile::from_json(&text) {
                Ok(p) => return p,
                Err(e) => { log::warn!("profile unusable ({e}); keeping it as .bak"); let _ = std::fs::rename(path, path.with_extension("json.bak")); }
            },
            Err(_) => {}
        }
        let p = Profile::new(super::app::level_seed(fresh_seed));
        let _ = p.save(path);
        p
    }
}
```

```rust
/// `[money, round, profile_seed, gold_count]` followed by 4 missions x
/// `[kind(0 cargo/1 race), seed, difficulty, length_m, time_limit, reward_base, best_medal, best_time]`.
pub fn menu_info(path: &Path, fresh_seed: u64, refresh: bool) -> Vec<f32> {
```

```rust
pub fn fill_state(out: &mut [f32; STAT_LEN], w: &World, money: u32, payout: u32, fps: f32, frame_ms: f32, seed: u64) {
    use crate::game::run::{bearing, Failure, Outcome, Phase};
    *out = [0.0; STAT_LEN];
    out[0] = fps; out[1] = w.vehicle.vel.len() * 3.6; out[2] = (seed & 0xFF_FFFF) as f32; out[3] = frame_ms; out[16] = money as f32;
    let Some(r) = &w.mission else { return };
    out[4] = match r.phase() { Phase::Ready => 1.0, Phase::Running => 2.0, Phase::Done => 3.0 };
    out[5] = r.time(); out[6] = r.mission().time_limit; out[7] = r.integrity();
    out[10] = r.next_index() as f32; out[11] = r.mission().checkpoints.len() as f32;
    out[17] = if r.mission().kind == crate::game::missions::MissionKind::Cargo { 0.0 } else { 1.0 };
    if let Some(t) = r.target() {
        out[8] = (t - w.vehicle.pos).len();
        let h = (w.cam.target - w.cam.pos).norm();
        out[9] = bearing(h.x, h.z, w.vehicle.pos, t);
    }
    match r.outcome() {
        Some(Outcome::Passed { medal, .. }) => { out[12] = 1.0; out[13] = medal as u8 as f32; out[14] = payout as f32; }
        Some(Outcome::Failed(f)) => { out[12] = 2.0; out[15] = match f { Failure::TimeUp => 1.0, Failure::CargoDestroyed => 2.0, Failure::Abandoned => 3.0 }; }
        None => {}
    }
}
```
